## 1. 资源预算（**逐项查证过，不是推断**）

| 需要什么 | 结论 | 证据 |
|---|---|---|
| 第二路脉冲定时器 | ✅ **够** | 当前只占用 **TIM2**(拍) / **TIM3**(脉冲) / **TIM4**(脉冲计数) / **TIM5**(时基) ⇒ **TIM1、TIM8、TIM12~17 全空闲** |
| 第二路 PUL 引脚 | ✅ 有候选 | `TIM8_CH1 = PC6` 或 `TIM12_CH1 = PB14`（**需实测确认该脚在本板上未被其它功能占**）|
| 第二路 DIR/ENA 引脚 | ✅ **现成** | **`PE10`/`PE11` 已在 `STEP_DO_MASK(0x0F00)` 里作预留位**（`src/step.h:39`）⇒ **无需扩掩码** |
| "走 N 步"硬件计数 | ✅ **更好** | **TIM1/TIM8 是高级定时器，有 RCR（重复计数器）** ⇒ 可直接硬件精确走 N 步，比现在的 `TIM4` 从模式更简洁 |
| SHM/WIRE 请求槽 | ⚠️ 需新增 | 需再要 4 个（第二轴的 rate/dir/ena/limit）。★ **注意 `16/17` 有被 `dclc` 抢走的前科**（§11.2）⇒ 必须"显式钉住 + 登记进保留集" |
| ⛔ 第二个编码器 | **阻塞** | AS5600 的 I2C 地址**固定为 0x36**（无地址选择引脚）⇒ 同一条 I2C 上挂两个**必然冲突** |
| ⛔ 第二个驱动器/电机 | **阻塞** | **台架上没有** |
| ⛔ ITCM 余量 | **阻塞** | **64/64 KB 100% 满**（`build.sh` 每轮都打印）⇒ 任何**新增 ISR 可达代码**前必须先腾 |

## 2. 三个阻塞项与各自的解法

| # | 阻塞 | 解法（按代价排序） |
|---|---|---|
| **B1** | 第二个 AS5600 撞固定地址 0x36 | ① **加 I2C 多路复用器**（TCA9548A，一片可挂 8 路，代价：程序里多一步"选通道"）② **开第二路 I2C 总线**（要占两个引脚 + 固件新驱动）③ **换编码器**：带地址选择的磁性编码器，或 SPI/ABZ 增量式（ABZ 还能顺便省掉 I2C 事务） |
| **B2** | 第二个驱动器/电机 | **采购**：同型号 TB6600 模块 + 同规格步进 + 24 V 供电余量。★ 若第二轴只是"证明多轴能力"，可先用**小负载/空载** |
| **B3** | ITCM 已满 | **结构性工作**：把当前 ITCM 驻留项按"是否真的每拍都要"重新审一遍（`gate_isr_itcm.py` 会列出闭包）；把"拍内低频"的搬回 flash，或**合并**同类小函数 |

## 3. 启动顺序（**清单**；未做完上一项不要开始下一项）

- [ ] **B3 先做**（唯一不依赖采购的一项）：腾出 ITCM 余量，并让 `build.sh` 的 ITCM 百分比**回到 <100%**
      ⇒ 验收：构建输出里 `ITCM:` 不再是 `100.00%`，且 12 套回归零新失败模式
- [ ] **B2 到位**：第二套驱动器 + 电机接好，先用**现在的单轴固件**把"第二个电机能转"验掉
      （即：先用 `0x39 sub=1..4` 的脚手架在**第二组线**上证明接线正确 —— 这一步**不需要多轴固件**）
- [ ] **B1 决策**：选 TCA9548A / 第二总线 / 换编码器（**建议 TCA9548A**：代价最小、改动局部）
- [ ] **结构改造**（①层）：`step.c` 单例 → **实例化**（`step_axis_t` + `step_axis[]`，
      引脚/定时器/计数方式/DO 位/DIR 极性 **全部走"装置属性声明"**，见 §10.1）
- [ ] **能力面扩槽**：第二轴 4 个请求槽 + 观测槽（**先钉住、再登记保留集**，见 §5.17/§5.22）
- [ ] **插补放 ③ 层**：多轴联动 = ③层算各轴分量 → 写各自 `wire[]`（**不要在固件里做插补**：
      契约里"怎么算"属 ③ 层）

## 4. 验收需要什么（**先说清，否则又会"宣称完成"**）

| 判据 | 需要 |
|---|---|
| 第二轴独立调速 | 第二套驱动+电机（B2）|
| 第二轴闭环（编码器反馈）| B1 解决 |
| **两轴联动（直线/圆弧插补）** | 上述全部 + 两个编码器同时可用 ⇒ 需**两路反馈的同步性**判据（这才是多轴的真难点）|
| A/B（单例 vs 实例化）| 两套硬件，或**同一轴跑两遍**（结构等价性）—— ★ 后者只能证明"没退化"，**不能证明"多轴能用"** |

## 5. 明确**不做**（避免铺摊子）

- **不做**"先用假数据/单元测试宣称多轴完成" —— 本项目的老族就是"宣称 > 实现"。
- **不做**在固件里写插补 —— 那是"怎么算"，属 ③ 层（契约判层表）。
- **不做**电路/电流环（TB6600 无接口，硬件缺）。
- **不做**"两轴共用 TIM3 不同通道"（那只能**同频** ⇒ 不是真多轴）。
