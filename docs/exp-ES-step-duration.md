# exp-ES —— 「走 N 步」的**时长**与**过冲的界**

> 一句话：把「声明的时间量」这一族做完最后一个域。结论有两条，一条是**验证**（脉冲频率与硬件计数
> 都精确），一条是**更正**（`step.h/step.c/main.c` 三处注释把"名义周期 0.37 ms"当成了过冲的**上界**，
> 实测被打破 **282 倍**）；外加一次**自我撤回**（我第一版的"观测放大过冲"结论不成立）。

- 工具：`tools/exp_es_step_duration.py`（11 条判据 / 1 SKIP）
- 产物：**交付档 hex 未变**（`e5a9aaa6…` —— 本次只改注释，逐字节验证）
- 运行记录：`.tmpctl/es_run3…es_run6.json`

---

## §1 为什么做这一条

`op=19 sub=15`「走 N 个脉冲自停」声明的量是**两个**：`N`（步）与 `f`（Hz）
⇒ **声明的时长 = N/f**。既有判据（`h723_step_pulsecount_test.py` P 组）只判**条数**，
没有任何判据把"声明的 N 与频率"合起来对**时间**判一次。

| 声明 | 判据 | 观测通道 |
|---|---|---|
| `f` Hz | **实现频率 = f**（±1%） | ΔTIM4 / Δtick（**最小二乘**，免疫起停延迟） |
| 到点自停 | 过冲(时间) = 过冲(步)/f ≤ **本次主循环最大间隔** | TIM4 快照 |
| 声明时长 | 实得时长 = 读回步数 ÷ 实现频率（**组合**） | 上面两个量 |
| 先到谁 | 限时先到 ⇒ `abort_n` 涨而 `done_n` 不涨 | `sub=16` |

## §2 ★★ 本实验最重要的一步：**先问"这个量能不能被观测通道测到"**

第一版直接量 `停止时刻 − 起始时刻`，得到"实测时长 = 声明 × **1.086**"，
**看起来像脉冲频率偏低 8%**。差一点就去"修"一个没坏的固件。

真相是**测量方法本身有偏**：静默模式下我 `sleep(N/f + 50 ms)` 再读，
读到的时刻是**"我发现的时刻"**而不是"它停的时刻"（+50 ms 余量 + 读延迟 ≈ +7~9%）。

换成**差分/拟合**测量（两端都在运行中，与起停时刻无关）后：

| 声明 | 实现（两点差分） | 实现（8 点最小二乘） |
|---|---|---|
| 2500 Hz | 2499.9（−0.004%） | 2499.8 ~ 2504.0 |
| 5000 Hz | 5000.9（+0.019%） | 5000.3（+0.006%） |
| 10000 Hz | 10000.0（+0.000%） | 9979.0（−0.210%） |

⇒ **脉冲发生器与 TIM4 硬件计数都是准的**（≤0.21%）。★ 两点差分本身还带一个 20 ms
读数偏斜（读 tick 与读 TIM4 是两帧）⇒ 在 2.6 s 跨度上变成 ±0.8% 的斜率偏差
（实测 5000 Hz 点因此偏到 −0.46%）⇒ 改用**最小二乘**把偏斜降成噪声。

★ 教训：**先问"这个量能不能被观测通道测到"，再问"它对不对"**。

## §3 ★★ 更正：注释里的「≤1 圈 ≈0.37 ms」不是一个界

`src/step.h` / `src/step.c` / `src/main.c` **三处**都写着"到点延迟 ≤1 圈 ≈0.37 ms"。
而 0.37 ms 是主循环的**名义**周期 —— **名义值不是上界**（与 P24「一个倍率 3.03」、
P25「取 `min` 就行」**同族**，这次错在**注释**里）。

真实机制：`step_tick` 每个主循环通过一次，检查 `TIM4_CNT >= goal` ⇒
**过冲(时间) ≤ 本次停脉冲前主循环的最大间隔**。实测量化（f=5000 Hz，声明 40 ms）：

| 条件 | 过冲(时间) | 与 0.37 ms 之比 |
|---|---|---|
| 名义（主循环自由，5 次） | **0 ~ 27 ms** | 0 ~ 73× |
| **注入一次大块 `0x22` 读**（板侧阻塞 ~100 ms，3 次） | **72 ~ 104 ms** | **195 ~ 282×** |
| 界（`g_loop_gap_max` = 91.5 ms 实测） | 每一条都 ≤ 界 ✓ | — |

### ★★ 由此得到的**可算设计规则**
> 要求过冲 ≤ `k` 步 ⇒ 必须 `f ≤ k / 主循环最大间隔`。
> 例：间隔 100 ms、要求过冲 ≤ 10 步 ⇒ `f ≤ 100 Hz`。

而"主循环最大间隔"本身是**可观测**的（`g_loop_gap_max`，SHM `OFF_WDT_STAT+116`）
⇒ 这条规则可以**在部署前算**，不需要试错。★ 这与本项目"把不确定性变成可算的量"是同一条路。

### 三处注释已按实测改正
并写明"名义 0~27 ms / 阻塞下 72~104 ms"。★ **交付档 hex 未变**（`e5a9aaa6…`）——
注释改动不影响二进制，这条本身是对"改的是不是只有注释"的逐字节验证。

## §4 时长怎么判：**组合**判据（因为"停止时刻"不可直接观测）

「实测停止时刻 − 起始时刻」在本平台上**不可直接观测**：
- **轮询**会阻塞主循环（把过冲从 0~7 ms 抬到 0~27 ms）；
- **静默**只能在事后知道"已经停了"，不知道**何时**。

⇒ 目前只能**组合**：`实得时长 = 读回步数 ÷ 实现频率`（两个量各自都被单独验过）：
```
读回步数 5021 ÷ 实现频率 5000.3 Hz = 1.004141 s
声明 N/f                          = 1.000000 s
差 +4.1 ms = 过冲  ≤ 界 91.5 ms   ✓
```
★ 要与组合值**独立互证**，需在 `step_tick` 停脉冲那一行记一个 `g_step_stop_tick`
（一行代码 + `sub=16` 的一个保留槽）⇒ 已登记为**观测面缺口**（**SKIP 不是 PASS**）。

## §5 ★ 一次**自我撤回**：单点 A/B 在方差大的量上会给出反号结论

E-S 工具第一版据**单次**对照宣称"紧轮询把'到点'过冲放大"（3.6 → 10.0 ms = 2.8×）。
下一次运行给出**相反方向**（4.6 → 1.0 ms = 0.2×）。改成**每条件 5 次**后：

| 运行 | 静默 [min, max] | 紧轮询 [min, max] | 判定 |
|---|---|---|---|
| es_run3 | 3.6（单点） | 10.0（单点） | "放大 2.8×" |
| es_run4 | 4.6（单点） | 1.0（单点） | "缩小 0.2×" |
| es_run5 | [4.2, 55.8] | [0.4, 11.6] | **区间重叠** |
| es_run6 | [0.0, 7.0] | [0.0, 27.0] | **区间重叠** |

⇒ **该断言不成立**（已记 `RETRACTIONS.md` P28）。可靠的方向性只有**注入阻塞**那一条
（100 ms 量级 ≫ 自然抖动）。工具现在把判据写成"两条件区间**重叠**、**不宣称方向**"。

★ 注意：E-R 那条"观测改变被测对象"仍然成立（限时流逝率 747 vs 990 ms/s 是**两次独立运行
都复现**的），但**不能**拿它来解释这个量 —— 这就是"机制听起来对"与"这个量上成立"的区别。

## §7 本次实验自己踩的坑（都留档）

1. **命令住在 `0x39` 的 sub-op 19 里**（不是 `0x19`），载荷必须 **6 字节**
   （少一字节 ⇒ `arg` 落进 `n>=6` 的门外 ⇒ **静默当 0**）。E-R 已踩过，E-S 第一版又踩了一次。
2. **静默模式的"时长"是"我发现的时刻"**（§2）⇒ 差点把测量偏置当成固件缺陷。
3. **两点差分的读数偏斜**变成斜率偏差（§2）⇒ 改最小二乘。
4. **单点 A/B 反号**（§5）⇒ 改成每条件多次 + 报区间。
5. `argparse` 的 `help` 里嵌了 `"` ⇒ Python 语法错（用「」代替）。

## §9 边界与未决

1. **"停止时刻"的直接时间戳仍缺**（§4）⇒ 组合判据已给出时长，但缺一次独立互证。
2. 过冲的界用的是 `g_loop_gap_max`（**开机以来**最大值）⇒ 偏松但方向正确；
   若要**每次运行**的紧界，需在停脉冲前记录本次运行的最大间隔。
3. 本实验不依赖电机是否转动（脉冲由 TIM3 硬件发出、由 TIM4 硬件计数）
   —— 凡"时长/频率"结论都与机械状态无关；凡"转了多少"的结论不在本实验范围内。
4. `sub=15` 的 **16 位钳位**（N>65535 ⇒ 65535）由既有 P5 判据覆盖，本实验不重复。
