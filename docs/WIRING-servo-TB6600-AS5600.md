# 接线表：H723 + TB6600 + 42 步进 + AS5600（24V 光耦继电器模块 = 第二阶段）

> 硬件：24V/3.2A 开关电源 · 24V 4路光耦继电器模块 · TB6600 · 42 步进 · AS5600（I2C）  
> 原则：**三个电压域不要混**，先跑通闭环，继电器最后加。

## 0. 三个域

| 域       | 电压        | 成员                                           | 接地              |
| ------- | --------- | -------------------------------------------- | --------------- |
| **逻辑域** | 3.3V / 5V | H723、TB6600 的 `PUL±/DIR±/ENA±`（光耦输入侧）、AS5600 | 板子 GND = USB 地  |
| **电机域** | 24V       | 24V 电源、TB6600 `VCC/GND`、电机相线、继电器触点侧          | 24V 负极，**保持浮空** |
| 隔离带     | —         | TB6600 输入光耦 / 继电器输入光耦                        | **两个地不要短接**     |

## 1. 24V 电源 → TB6600

| 从              | 到            | 说明                   |
| -------------- | ------------ | -------------------- |
| 24V PSU `+24V` | TB6600 `VCC` | TB6600 收 9~42V，24V ✓ |
| 24V PSU `0V`   | TB6600 `GND` |                      |

★ **42 电机电流设 1.5~2.0 A**（拨码），细分建议 8 或 16（3200 脉冲/圈）。  
★ 24V/3.2A 对单只 42 电机够用；**别把 24V 负极接大地**，否则隔离白做。

## 1.1 ★ TB6600 拨码 —— **本机这块驱动器的实际表（照外壳丝印抄录 2026-09-15）**

> 网上的 TB6600 拨码表**各厂不同**（我查了 4 份来源，四张表互不相同）⇒ **只认这块板上的丝印**。
> 下表就是这块板丝印上的内容。壳子右侧标注顺序是 `SW6 SW5 SW4 SW3 SW2 SW1`（SW6 最上），
> **按丝印编号对齐，别按物理位置第几个。**

|---|---|---|---|---|
| 0.5 | 0.7 | ON | ON | ON |

### ⇒ 本实验的拨法

```
S1=OFF  S2=ON  S3=OFF      → 细分 8 = 1600 脉冲/圈
S4=ON   S5=ON  S6=OFF      → 1.5A 档 (峰值 1.7A)
```

★ **为什么是 1.5A 档**：这块板的 1.5A 档峰值正好标 **1.7A**，与最常见的 42 步进
（17HS4401）额定 1.7A 严丝合缝。**但以电机铭牌为准**：额定 1.2A 的电机应选 `ON OFF ON`(1.0A)，
**绝不超过铭牌值**（过流损坏不可逆）。
★ **为什么细分选 8 不选 16**：TB6600 的 PUL 输入光耦带宽有限，细分高 ⇒ 同转速脉冲频率翻倍；
且**细分不提高精度**（由机械决定），只让运动更平滑。
★ **这两个数都不影响闭环**：位置由 AS5600 给，脉冲只是"推力"。

## 2. H723 → TB6600（**共阳接法**，3.3V MCU 最稳）

| H723 引脚                | U9 脚   | 接到 TB6600                       | 作用              |
| ---------------------- | ------ | ------------------------------- | --------------- |
| **PA6**（TIM3_CH1, AF2） | **19** | `PUL−`                          | 步进脉冲（硬件 PWM 产生） |
| **PE8**                | **35** | `DIR−`                          | 方向              |
| **PE9**                | **36** | `ENA−`                          | 使能              |
| 板 **+5V**              | 3 或 4  | `PUL+` `DIR+` `ENA+` 三个正端**并接** | 共阳              |
| 板 **GND**              | 13     | （TB6600 的负端**不**接 GND）          | 逻辑参考地           |

```
       板 +5V ──┬── PUL+      MCU 拉低 = 光耦导通 = 收到脉冲
                ├── DIR+
                └── ENA+
   PA6 (PUL−) ───── 由 MCU 灌电流到地
   PE8 (DIR−) ─────
   PE9 (ENA−) ─────
```

★ **先量一次再全接**：万用表 mA 档串在 `+5V → PUL−` 上。  
· 若 **≤ 8 mA** ⇒ 直驱没问题   
· 若 **8~15 mA** ⇒ 也能用（H723 单脚绝对上限 20 mA），但建议在 `PUL−/DIR−/ENA−` 各串 **220~330Ω**  
· 若 **> 15 mA** ⇒ 必须加缓冲（ULN2003 或 2N7000）  
★ **ENA 的有效极性要实测**：TB6600 有正/反两种标注，有的板子"光耦导通 = 使能"，有的相反。  
上电后先让电机轴能被手转动（失能）还是锁死（使能），据此定极性。  
★ **PA6 原来是 HIL PWM（1 kHz 驱动 HIL 输出）** —— 本实验把它改作步进脉冲，  
两者不能同时用（同一个 TIM3_CH1）。HIL 那条链路本轮先让出。

### 2.1 ★★★ 判接线：**PA6 静态电平探针**（电机不转时**先用这个**，别用万用表直接量脉冲）

```
python tools/h723_stepper_test.py probe high   # PA6 → GPIO 输出 3.3V
python tools/h723_stepper_test.py probe low    # PA6 → GPIO 输出 0V
python tools/h723_stepper_test.py probe af     # 还原 TIM3_CH1（CC1E=0，仍无脉冲）
python tools/h723_stepper_test.py probe od 1   # PA6 输出类型改**开漏**（候选修复，见 §2.2）
```

**为什么必须有它**（2026-09-15 实测踩到）：
万用表 **DC 档量 500 Hz / 50% 方波，读的是平均值 ≈1.65 V** ——
"线通（被光耦 LED 钳到 ~1.2 V）"与"线断（浮空 ~4.5 V）"在表上只差一点点，**判不了**；
更要命的是"脉冲还在不在跑"本身还是个变量（有**限时**，到点自动停 ⇒ 停下来后 PA6 = 静态低 = 0 V）。
两件事叠加 ⇒ 读数毫无信息量。**把 PA6 摘下来给一个确定的静态电平，歧义就没了。**

| U9 pin19（high/low） | TB6600 `PUL−`（high/low） | 结论 |
|---|---|---|
| 3.3 V / 0 V | ~2~4 V / ~1.0~1.5 V | ✅ 线通、端子对 |
| 3.3 V / 0 V | **4.5 V / 4.5 V 纹丝不动** | ✗ **线断 / 插错端子** |
| 3.3 V / 0 V | 0 V / 0 V | ✗ `PUL−` 被短到 GND |
| 本身不是 3.3 V/0 V | — | ✗ pin19 认错了 / 板载器件拉住（`PA6` 网络名亦为 `DCMI_PIXCLK`，板上有摄像头座） |

★ 探针**零风险**：进入前先关 `CC1E`（保证无脉冲），只切 `MODER/AFRL/OTYPER/PUPDR`。
★ **判据要成对读**：只看一档分不清"线断"与"LED 不导通"，两档一起看才能把两者拆开。
★ ★★ **上表只对 `probe` 的 GPIO 输出档（`low`/`high`）成立。**
`probe af`（TIM3/AF、无脉冲）下引脚是**高阻**，`−` 端会被外面拉到 ~4.5 V ——
**那不是断线，别拿它判。** 见下面的实测记录。

> **实测记录 2026-09-15**：A(`PA6`)=**0.116 V** / B(`PUL−`)=**4.5 V** / C(`PUL+`)=**5 V**。
> ★★ **2026-09-15 更正：上面这次读数被误判了。** 真实原因见下。
> 后来用户补测：`DIR− = 3.4 V`、`ENA− = 3.4 V`（= MCU 推挽高打上去的）、所有 `+` 端 = 5 V、
> **`PUL−` 换了一根线仍然是 4.5 V**。
>
> **物理硬约束**：推挽输出**不可能**把引脚抬到 VDD(3.3 V) 以上。
> ⇒ `PUL− = 4.5 V` 说明那一刻 **MCU 没在驱动这个脚（高阻）**，4.5 V 是外面经
> "驱动器内部电阻 + 光耦 LED"把脚拉上去的。**它根本不是"断线"的证据。**
>
> 芯片自读 `GPIOA_IDR`（引脚**真实**电平，与谁在驱动无关）证实：
> | 状态 | MODER | CC1E | **IDR(PA6)** |
> |---|---|---|---|
> | `probe high` | 1(输出) | 0 | **1** ✓ 我们驱动高 |
> | `probe low` | 1(输出) | 0 | **0** ✓ 我们驱动低 |
> | **`probe af`（TIM3, 无脉冲）** | 2(AF) | 0 | **1** ⇒ ★ **高阻** |
> | AF + 500 Hz（`idrwatch`） | 2(AF) | 1 | **0/1 都出现** ⇒ **真的在翻转** |
>
> ⇒ **两条结论**：
> 1. ☆☆☆ **`PA6` 在"AF 模式 + `CC1E=0`（无脉冲）"时是高阻，不是低电平。**
>    所以"没脉冲"时 `PUL−` 会浮到 ~4.5 V —— 极像"断线/插错端子/软件没输出"。
> 2. **脉冲其实一直在出**（`CC1E=1` 时 IDR 同时出现 0 和 1）⇒ AF2/TIM3 通路是通的。
>
> ★ 教训：**"配置全绿"（`MODER=AF`+`AFRL=2`+`CNT`在跑+`CC1E=1`）与"引脚真的在动"是两件事**；
> 唯一能分辨的是 **`IDR`（引脚真实电平）**。而且**判"有没有脉冲"必须在有脉冲时判** ——
> 拿"无脉冲空闲态"的电压去判，读到的只是高阻 + 外部上拉。

### 2.2 ⚠️ 待验证的**第二个**风险：3.3 V 推挽高电平可能**关不断** 5 V 光耦

共阳接法下，"不导通"靠 MCU 输出高。而 TB6600 光耦链是 `+5V → R(内部限流) → LED → PUL−`：
- 若内部 R 较大（≈4.7 kΩ）：3.3 V 高时链上只剩 `5 − 3.3 = 1.7 V`，**LED 基本不导通** ✅
- 若内部 R 较小（≈300~500 Ω）：3.3 V 高时 LED 仍有 **数 mA** ⇒ **一直算"有脉冲"，步进不计数** ✗

⇒ 判别与修法统一在一条命令上：`probe od 1` 把 PA6 改成**开漏**
（低 = 灌电流导通；高 = 高阻，由驱动器内部电阻把 LED 关掉）。
开漏是"3.3 V 逻辑驱动 5 V 光耦输入"的**标准正解**，且不会向 5 V 侧倒灌。
★ 前提确认：H723 的 **PA6 是否为 5V 容忍（FT）脚** —— 开漏高阻时引脚会被拉到 ~5 V，
若不是 FT 脚则**不能**这么做，必须改用外部缓冲（ULN2003 / 2N7000）。

## 3. H723 → AS5600（I2C2）

### ★★ 第一版此表有两处错误，已按 ams 官方 datasheet 更正 (2026-09-15)

| 模块端子 | 接到 | 说明 |
|---|---|---|
| **`5V`** | **U9 pin 3/4（板 +5V）** | ★★ **不是 3.3V**。模块只引出 `5V` 一脚 ⇒ 它是 **5V 模式**（板载 LDO 降 3.3V）。喂 3.3V 会导致 LDO 输出低于 AS5600 的 3.0V 下限 ⇒ **芯片不工作、但上拉仍把线拉高**（实测症状就是"有上拉、无 ACK"） |
| `GND` | **U9 pin 13** | ★ 用万用表**通断档确认真的通** —— 这根最常漏 |
| `SDA` | **PB11（U9 pin 42）** | |
| `SCL` | **PB10（U9 pin 44）** | |
| **`PGO`** | **悬空**（不要接 GND） | ★ 官方：`PGO` **内部上拉**；**悬空/VDD = 正常工作模式**，**接 GND = 进入编程模式**。第一版误写"PGO → GND"，会把它推进编程模式 |
| **`DIR`** | **GND** | ★ 官方：`DIR = GND` ⇒ 顺时针角度增加；`DIR = VDD` ⇒ 逆时针增加。**不要悬空**（无内部上拉，悬空不确定）。第一版误写"悬空" |

### 接之前必须量的三个量（第 2 步决定"能不能直接接"）

> **✅ 2026-09-15 实测已连通**：`PB10=SCL / PB11=SDA`，地址 0x36 应答，RAW_ANGLE 可读。
> 当时的"不通"**是固件里的 bug**：`GPIO_MODER` 是**每引脚 2 位**，我用了 1 位/引脚的掩码 ⇒
> PB10/PB11 从未切成输出 ⇒ START 条件不成立。★ 靠"**写低后读回 IDR**"的自检抓住。
> ★ **更正 (同日)**: 先前写的"MH=1 磁场太强、磁铁太近"**是错的** —— 那是我把
> **16 位读法用在 8 位寄存器**(0x0B) 上、解码取错了字节(取到 0x0C 的角度高位)。
> 正确读法下 `STATUS(0x0B) = 0x27` ⇒ **MD=1 磁场正常**。又是一个"宽度/偏移"错。
> ⇒ 现在 0x0B 按**单字节**读。

1. 模块 `5V` ↔ 板 `+5V`、模块 `GND` ↔ 板 `GND`：**通断档确认**
2. ⚠️ **模块 `SDA`/`SCL` 对 `GND` 的空闲电压**：
   - **≈3.3 V** ⇒ 上拉挂在模块自己的 3.3V 轨上 ⇒ **可以直接接 MCU** ✅
   - **≈5 V** ⇒ 上拉挂在 5V 轨上 ⇒ **先别接**（STM32H7 的 IO **不 5V 容忍**），要加电平转换
3. 模块 `5V`–`GND` 之间确实有 5 V

### 协议参数

- I2C 地址 **0x36**（7 位，不可配）
- 原始角度 **0x0C/0x0D**（12 位，0~4095 = 0~360°）
- 磁铁检测位在 **STATUS = 0x0B**（不是 0x1A；0x1A 是 AGC 自动增益）
- 走线远离电机四根相线、尽量短；先按 **100 kHz** 跑通再提速
- **磁铁必须与轴同轴**（0.5~3 mm 间隙），偏心直接变成角度非线性误差

> ★★ **2026-09-15 实际情况：本轮不用继电器** —— 24V 直接进 TB6600（用户已按此接线）。
> 这反而更干净：少了一整类"输入侧以 24V 负极为参考"的风险。PE10/PE11 悬空，
> 固件把它们**驱动成高电平**（确定电平，不是悬空）。下面的继电器方案留作第二阶段参考。
> ★ 拨码务必先设（见 §1.1）。


## 4. 继电器模块 —— **建议第二阶段再接**（本轮未使用）

**为什么不建议第一版就接**：24V 光耦继电器模块的输入侧是以 **24V 负极**为参考的，  
接上就等于把**逻辑地和 24V 负极短在一起**；同时 24V 通断的浪涌噪声会串进 I2C ——  
正好打在这套里最脆的那条线（AS5600）上。先把闭环跑通，再单独加它。

要接的时候：

| 继电器模块    | 接到                                            |
| -------- | --------------------------------------------- |
| `VCC`    | 24V PSU `+24V`                                |
| `GND`    | 24V PSU `0V`（**这一步就把两个地连上了，务必先想清楚**）          |
| `IN1`    | **PE10**（U9 pin 37）—— 接之前**先量** IN1 对 GND 的电流 |
| `IN2..4` | PE11/PE12/PE13（U9 pin 38/39/40），备用            |
| `COM1`   | 24V PSU `+24V`                                |
| `NO1`    | TB6600 `VCC`（**做 24V 主电源闸门**）                 |

★ **触点只串 24V 主回路，绝不要串电机相线** —— 相线要按 A+/A−/B+/B− 换相，继电器做不到。  
★ 若 IN1 对 GND 的电流 > 8 mA ⇒ 加 **ULN2003 / 2N7000** 缓冲，别让 MCU 脚直接灌。  
★ 日常"停/走"用 **ENA**，不要靠继电器反复通断 24V（触点寿命 + 每次上电驱动器都要重新使能）。

```

## 5. 引脚/外设占用一览（避免撞车）

| 资源 | 现状 | 本实验 |
|---|---|---|
| TIM2 | 100 µs 拍（ISR） | 不动 |
| TIM3_CH1 / PA6 | HIL PWM 1 kHz | **改作步进脉冲**（ARR 定频率） |
| USART1 / PA9,PA10 | DCL 协议 | 不动 |
| USART2 / PA2,PA3 | Modbus | 不动 |
| ADC / PA5 | HIL 反馈 | 不动（可留作第二反馈源） |
| DI / PC0~PC3 | 4 路数字输入 | 备用（限位/原点开关） |
| DO / PE0~PE15 | **当前没接通**（`GPIO_MASK` 恒 0） | 本实验接通；用 PE8~PE13 |
| **I2C2 / PB10,PB11** | **空闲（工程内没有任何 I2C 代码）** | **新增驱动**接 AS5600 |
```
