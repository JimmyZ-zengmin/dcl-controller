## 2. H723 已经做到什么（且大多优于 S3）

| 能力 | S3 实测 | H723 实测 | 评价 |
|---|---|---|---|
| 拍周期 | 99.9973 μs | **100.0000 μs**（LA 实测众数，96% 命中）| ✅ 更准 |
| 拍抖动 | 极差 0 cyc | **极差 0 cyc**（min=max=40000）| ✅ 持平 |
| 空拍骨架 | 49 cyc @240MHz = 204ns | 95 cyc @400MHz = **237ns** | ⚠️ 略慢（绝对时间），但抖动同为零 |
| 单条路由 | 234 cyc | **56.0 cyc** | ✅ **快 4.2×** |
| 128 条全表扫占拍 | — | FLASH 65.8% / **ITCM 18.3%** | ✅ ITCM 落位是设计前提 |
| 分档调度收益 | 2.59× | **2.59×**（同语义） | ✅ 一致 |
| 热重载延迟 | — | **3.6 μs**（ITCM 字拷贝） | ✅ 远优 |
| 协议帧格式 | — | **逐字沿用，脚本零改动** | ✅ |

### 已落地的机制（这些不用再做）
- ITCM/DTCM 落位 + 同镜像 A/B 实验（16 次构建坐实成本 = f(addr mod 32)）
- 桶化分档调度（div0 全跑 + div1 tick%10 + div2 tick%64，**已修 H9 缺陷**）
- 19 原语 + 逐原语实测成本表 `k_op_cost_itcm[19]`
- deploy：下载前静态校验 → staging → 热重载 → `APPLIED_SEQ` 生效确认
- transport 解析器（7 态状态机 + F1 分块 CRC）
- USART1 驱动（RXNE 中断 + 环形缓冲 + 错误标志逐个清）
- 观测面：64 个变量 + `obs_anchor()` 统一锚定
- 冷启动单一入口 `cold_start_reset()` + 栈哨兵

## 3. 缺口清单（按优先级）

### W1（P0）运行控制 + SHM 读写 — 7 条命令
```
0x11 START   S3 main.c:895  —— 含 F11 预算兜底 + OA13 幂等 + Seq 运行态重置
0x12 STOP    S3 main.c:925  —— 含 P1-2 outputs_safe() 安全态
0x13 RESET   S3 main.c:927  —— cold_start_reset()
0x20 READ           S3 main.c:163  —— valid_addr 守卫
0x21 WRITE          S3 main.c:179  —— write_allowed NaN/Inf 守卫
0x22 READ_BURST     S3 main.c:170  —— valid_range 守卫
0x23 WRITE_BURST    S3 main.c:188  —— 全量预检后写
```
**必须逐字搬的 4 个安全守卫**（S3 main.c:83-140）：
- `valid_addr()` —— 4 字节对齐 + 地址区间白名单（H723 要换地址表）
- `valid_range()` —— burst 起止都须同区
- `is_finite_bits()` + `shm_off_is_float()` + `write_allowed()` —— NaN/Inf 注入防护
- `outputs_safe()` —— STOP/RESET 后执行器归零

### W2（P0）Force + persist — 2 条命令 + 1 个模块
```
0x24 FORCE        S3 main.c:204  —— [idx:u16][mode:u8][val:f32]，OA9 强制值须写 FORCE_VAL
0x43 persist 观测  S3 persist/persist.h (341 行)
```
**前置**: SHM 要新开 FORCE_MASK / FORCE_VAL 区 —— 当前落在 `OFF_RSVD_EXEC_DOMAIN`（0x47F0，704B）。
- `FORCE_MASK_WORDS = MAX_WIRES/32 = 4` → 16B
- `OFF_FORCE_VAL = 128 × f32` = 512B
- 合计 528B < 704B ✅ 但**必须改断言**（把保留洞拆成真区，`_Static_assert` 尺寸常量要同步改）

### W3（P1）Sequencer — 1 条命令
```
0x44 SEQ_DEPLOY   S3 main.c:650  + DESIGN-sequencer.md
```
**前置**: SHM 要新开 `OFF_SEQ_CTRL`（`SeqCtrl_t` 数组）—— 当前落在 `OFF_RSVD_DSL_DOMAIN`（0x3840，3136B）。

### W4（P1）Modbus 通信域 — 3 条命令 + 370 行
```
0x60 MB_INJECT   0x61 MB_RESP   0x62 MB_CFG
core0/modbus.c (370 行) —— 含 mb_tick 每拍限速
问题: S3 用 UART1，H723 当前只有 USART1。需配 USART2 (PD5=TX/PD6=RX) 或复用单口。
```
**前置**: `OFF_MB_SET`（0x4AA0，已预留 64 WORD）+ `OFF_MB_TAIL`。

### W5（P2）外设域 — macro + ADC + DI/HIL/AI
```
0x30 MACRO_UPLOAD / 0x31 MACRO_CTRL  (macro_loop.h 234 + macro_exec.h 97)
ADC 16 位 + DMA → SENSOR_MAP          (替代 DHT22)
di/di.h (92) + hil (178) + ai (143)
```
**前置**: SHM `OFF_RSVD_DSL_DOMAIN` 还要放 macro run 区。

## 6. 开发纪律（本次采用的"先开发后审计"变体）

用户决定改为**先开发后审计**（不再每步停下等审计）。补偿措施：

1. **每步必测**：任何命令实现后立刻跑对应的 Python 验证脚本，绿了才继续
2. **回归闸门**：每完成一个 W 波次，重跑 `h723_proto.py`（必须仍 12/12）
3. **宣称=实现**：改 `DCL_CAP_H723_IMPL` 必须同时改 `transport.h` 的 NOTYET 清单（有 `_Static_assert` 兜底）
4. **新域必登记**：任何新 SHM 区必须同时改 ①偏移宏 ②`_Static_assert` 布局断言 ③`cold_start_reset()`
5. **事故留痕**：每个踩坑在代码旁写注释 + 更新 docs/

审计推迟到全部 W 波次完成后一次性做（对照 S3 的 4 轮审计口径）。
