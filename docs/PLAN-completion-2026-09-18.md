| # | 动作 | 代价（已侦察） |

| 3.1 | **`OUTPUT ... PERIOD=`** | **纯 `dclc` 改动** ✓ —— 周期字段本来就在 `RouteEntry.period` 低 2 位、`engine_build_buckets` 也在用；DSL 只是拒收。**它解锁的是"能把路由放到 div1/div2"** ⇒ 这是核心能力宣称 |

| 3.3 | `THR=` 放宽到变量 · `CONST` 接受科学计数法 | 纯 `dclc` 解析器 ✓ |
| 3.4 | **`LUT` 暴露** | ★★ **不是接线活**：`0x23` 的能量守卫允许写 `g_shm+OFF_LUT_DATA`（表**今天就能上传**），但 **`0x10 deploy` 不碰 LUT 区** ⇒ **表不在程序里**：上电自动装载后是残留/零，且**不进 SD A/B 持久化**。⇒ 需要先决定"表住哪"（扩 deploy 载荷 / 新命令进持久化镜像 / 声明"LUT 表由上位机每次重下"）。**先做最小验证把这个缺口钉成判据，再决定** |
| 3.5 | `MOD` | **引擎没有**（`ARITH` 六种模式里没有）⇒ 要动原语（①层）。**除非有明确需求，否则不做** |
