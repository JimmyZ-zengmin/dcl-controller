# THEORY —— 为什么"确定性推理时间"在这套架构上成立

> 对应 `README.md` §2。本文是**可证性论证**，不是实现说明。
> 凡结论都标注**是"论证的"还是"待实测的"**（本项目铁律：反推量必须标注假设）。

---

## 1. 可证性的根：控制流与数据无关

### 1.1 通用 WCET 的四大难题，以及本引擎砍掉了哪些

| 难题 | 传统 C 代码 | 本引擎（路由表） | 固定拓扑 CNN |
|---|---|---|---|
| 循环边界不定 | ✗ 常犯 | ✅ 无循环 | ⚠️ **有循环，但边界是编译期常量** |
| 间接跳转 | ✗ 常犯 | ✅ 无 | ✅ 无（禁函数指针） |
| 递归 | ✗ | ✅ 无 | ✅ 无 |
| 不可行路径 | ✗ | ✅ 无 | ✅ 无 |

★ **诚实更正**：`docs/ARCH-EXECTIME-COMPUTABILITY.md` 原写"四大难题**全砍了**"。
引入定长循环后，该句应改为：**"三个全砍；循环边界保留，但为编译期常量。"**
定长循环是 WCET 分析里**最简单**的一类（trip count 已知 ⇒ 可完全展开计数），
但仍**必须显式声明**，否则那份文档变成假宣称。

### 1.2 判据形式

> **同一个二进制 + 同一组输入 ⇒ 同一条指令序列 ⇒ 同一个周期数。**

只要满足 §3 的陷阱清单，这条就成立。**推论**：
- 可以**重放**（同输入 ⇒ 逐位相同输出 + 相同周期）
- 可以做**时序回归**（本项目已有的做法）
- 可以**事前**给出最坏界

★ 注意措辞：是"**同一组输入 ⇒ 同一周期数**"，不是"**任意输入 ⇒ 同一周期数**"。
后者更强也更难（需要连数据相关的访存都消除）。本课题要的是**前者 + 一个可算的上界**。

## 2. 为什么 TFLM / Cube.AI 拿不到这个性质（机制级）

| 机制 | 后果 |
|---|---|
| `MicroInterpreter::Invoke()` 经 **算子解析器的函数指针**分派 | **间接跳转** ⇒ 目标地址依赖运行期注册表 ⇒ WCET 工具无法确定被调者 |
| 多个 kernel 内含**数据相关分支**（padding 边界、量化 clamp、稀疏跳过） | 分支取/不取随数据 ⇒ 周期数随数据 |
| tensor arena 由 `AllocateTensors()` 在**给定缓冲内规划** | 仍是**静态**（这点它对，与本项目一致），但**布局由运行期决定** ⇒ 地址不确定 ⇒ 访存代价不可静态绑定 |
| 算子实现随版本变化 | 成本模型**无法跨版本稳定** |

⇒ 结论：**TFLM 可以"跑"，但给不出"证"。** 两者不是同一个产品。

★ **可以用 TFLM 的地方**：**离线**训练与量化（`TFLiteConverter` 的 INT8 后训练量化）。
本课题只用它做上游，**不用它做内核**。

## 3. 破坏可证性的陷阱清单（逐条带判据）

| # | 陷阱 | 机制 | 处置 | 判据（能失败） |
|---|---|---|---|---|
| 1 | ★★★ **Denormal** | 未开 flush-to-zero 时，非规格化操作数走慢路径/陷入 ⇒ **周期数随数据** | 打开 **`FPSCR.FZ`** | 关掉 FZ 的对照档**必须量出 `emax` 差异**；开了则两次不同输入 `emax` 相同 |
| 2 | ★★ **cache / 总线** | 代码落 flash ⇒ 取指受 I-cache 与 AXI 支配；数据落 AXI ⇒ cache 命中不可预测 | 代码进 **ITCM**，arena 进 **DTCM** | `gate_isr_itcm.py` 闭包覆盖新 kernel；arena 地址落在 DTCM 段内（可读回核对） |
| 3 | ★★ **对齐** | int8 卷积做滑动窗时常见非对齐访存（`M7` 对非对齐 4 字节访问代价高/可 fault） | 显式对齐 + 用对齐后的 load；不做"跨字拼装" | 用**非对齐起始偏移**扫一遍输入 ⇒ `emax` 必须不变 |
| 4 | ★★ **早退** | `if (acc > th) break;` / "置信度够高就跳过" | **禁止**（写进 review checklist） | 负对照：故意插一条数据相关早退 ⇒ "两次输入同 `emax`"判据**必须变红** |
| 5 | ★ **除法** | `VDIV.F32` 延迟固定但长（~14 cyc）；若落在内层循环会放大 | 卷积/池化内层**不用除法**；必要的倒数改为**编译期常量** | 源码级判据：kernel 内层无 `/` |
| 6 | ★ **动态 padding** | 边界处理写成数据相关分支 | padding 在**编译期**定死（`same`/`valid` 选定即固定） | 源码级：无 `if (idx < 0 \|\| idx >= N)` 形式的分支 |
| 7 | **FPU 上下文** | 若 ISR 引入 FPU，潜在 lazy stacking 代价 | 现状：ISR 已在跑 f32 ⇒ **无新增** | 对比开/关 FPU 使用的 `emax` |
| 8 | **中断抢占** | 更高优先级 ISR 会拉长本段 | 现状：TIM2 优先级 0（最高），USART1 = 0x80 ⇒ **不抢占** | 实测：满速收发协议 + 跑推理 ⇒ `emax` 不变 |
| 9 | **libc** | `memcpy`/`expf` 等引入未受控代码 | 热路径不用 libc（本项目既有纪律） | `gate_isr_itcm.py` 闭包不含 libc 符号 |
| 10 | ★ **层间转变** | 照 `OP_TRANS_COST` 的先例：**纯可加不是上界** | 成本模型显式含**每层固定开销**项 | 留点验证必须覆盖"层数不同"的网络（不只是"同结构不同大小"） |

## 4. 成本模型（三端 + 层开销）

> 形制照本项目既有的扫描段模型：`C_other + Σ m_op × 条数 + k × 转变数`。
> ★ 单位约定：本项目 `0x38` 的 `emax` 单位是 **TB**（TIM5 @200 MHz ⇒ 1 TB = 5 ns），
> **TB × 2 = cyc @400 MHz**（这个换算是 §5.40 家族的坑，**引用必须带上**）。

```
T_infer  =  T_fixed            （推理固有开销：入口/出口/清缓冲）
          + Σ_layer [ MACs_layer × c_mac        ← 计算
                    + W_layer   × c_wmove       ← 权重搬运
                    + A_layer   × c_amove       ← 激活搬运
                    + k_layer                   ← 层开销（循环建立/边界）
                    ]
```

| 常数 | 含义 | 现状 |
|---|---|---|
| `c_mac` | 单次乘加 | ★ **待实测（Q1）**；预估 f32 ≈ 4 cyc · int8+DSP ≈ 0.5 cyc |
| `c_wmove` | 每个权重的一次搬入 | 若权重住 **ITCM `.rodata`** ⇒ ≈ 0（零等待，可能被折叠进 MAC 的访存槽） |
| `c_amove` | 每个激活的一次搬入/搬出 | 住 **DTCM** ⇒ 单周期 |
| `k_layer` | 每层固定开销 | ★ **待实测**；先验：几十 cyc/层 |
| `T_fixed` | 推理固有 | ★ **待实测** |

### 4.1 为什么必须有"层开销"项

本项目已经吃过一次：`OP_TRANS_COST` 是**发现"纯可加不是上界"之后补上的转变项**。
⇒ **同理**：不能假设 `T(layer1) + T(layer2) = T(layer1+layer2)`。
留点验证**必须包含"层数不同"的样本**，否则这个模型在换网络时会静默失效。

### 4.2 与既有预算门的接口

```c
/* 部署门：扫描段 + CNN 切片 ≤ 拍长 */
_Static_assert(EXEC_BUDGET_CYCLES + CNN_SLICE_CYCLES <= CLK_TICK_CYCLES, "...");
```
★ 与 `EXEC_BUDGET_CYCLES` **不是同一个量**：那是"引擎扫描段"的判据，这是"推理切片"的预算。
**两个量两个名字**（本项目"一个语义两处存放"族的直接推论）。

## 5. 定长循环怎么算（把"常量"变成"可计数"）

固定拓扑 ⇒ 每层循环可**完全展开计数**：

| 层 | 循环结构 | MAC 数（编译期常量） |
|---|---|---|
| Conv1D(ch_in=1, ch_out=C, k, L) | `for o<L, for c<C, for t<k` | `L × C × k` |
| MaxPool(p) | `for o<L/p, for c<C, for t<p` | 比较，非 MAC：`(L/p) × C × p` |
| GAP(C) | `for c<C, for o<L` | 累加：`C × L` |
| FC(C, N) | `for n<N, for c<C` | `C × N` |

⇒ **`MAC 数` 与拓扑一样，是编译期常量。** 这是 Q2 成立的全部依据。
见 [`kernels/dcnn_topology.h`](../kernels/dcnn_topology.h) 的 `DC_*` 常量与断言。
