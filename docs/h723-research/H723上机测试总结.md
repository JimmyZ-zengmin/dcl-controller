```

## 4. RCC 寄存器布局 (H723 value line, RM0468)

```
RCC_BASE = 0x58024400

RCC_CR        (0x00): PLL1ON[24], PLL1RDY[25]
RCC_CFGR      (0x10): SW[2:0], SWS[5:3]  ← 仅时钟开关!
RCC_D1CFGR    (0x18): HPRE[3:0], D1PPRE[6:4], D1CPRE[11:8]
RCC_D2CFGR    (0x1C): D2PPRE1[6:4], D2PPRE2[10:8]
RCC_PLLCKSELR (0x28): PLLSRC[1:0], DIVM1[9:4]
RCC_PLLCFGR   (0x2C): PLL1VCOSEL[1], DIVxEN[18:16]
RCC_PLL1DIVR  (0x30): DIVN1[8:0], DIVP1[15:9], DIVQ1[22:16], DIVR1[30:24]
RCC_APB2ENR   (0x0F0): TIM1EN[0]  ← H723 专用偏移, 非 H743 的 0x110

PWR_BASE = 0x58024800
PWR_CR3 (0x0C): VOS[5:4], VOSRDY[6]

FLASH_ACR = 0x52002000: LATENCY[3:0], WRHIGHFREQ[5:4], PRFTEN[8], ARTEN[9]

## 5. 关键错误与修正

| # | 错误 | 根因 | 修正 |
|---|------|------|------|
| 1 | `#include <stdint.h>` 缺失 | — | 加上 |
| 2 | FPU 未使能 | SystemInit() 空函数 | 加 `SCB_CPACR \|= 0xF<<20` |
| 3 | APB2ENR 偏移错误 | 用 H743 的 0x110 | 改为 H723 的 0x0F0 |
| 4 | DIVM1=3 超 PLL 输入上限 | Fref=21.3MHz>16MHz | DIVM1=4→Fref=16MHz |
| 5 | FLASH_ACR 未开 PRFTEN/ARTEN | 默认关闭 | 设为 0x337 |
| **6** | **时钟切换瞬间死锁** | **总线分频器从未配置** | **见 §6** |
| **7** | **RCC_PLLCFGR `=` 清零关键位** | **应为 `\|=`** | **改为 `\|= (1<<18)`** |
| **8** | **HPRE 写到 RCC_CFGR (0x10)** | **实际在 RCC_D1CFGR (0x18)** | **修正寄存器地址** |
| **9** | **512KB 循环遍历超 100μs** | **-O0 下 1024 次迭代太慢** | **仅遍历活跃路由数** |

## 6. PLL 时钟切换: 已解决问题

### 6.1 544MHz 稳定运行 (当前状态)

```
VOS0 + PLL544MHz + HPRE=/2 + D2PPRE2=/4 + FLASH_ACR=0x324 → ✅ 稳定运行
```

**解决方案**: 采用阶梯式切换策略
1. 先切到 288MHz (VCOSEL=1) 过渡验证安全
2. 回 HSI, 重配 PLL 到 544MHz (VCOSEL=0)
3. 设置 FLASH_ACR=0x324 (4WS)
4. 切换成功, TIM1=136MHz, ISR=100μs 稳定

### 6.2 历史问题 (已解决)

```
VOS1 + PLL272MHz + D2CFGR(/2)     → ❌ 死锁 (已解决: 改用阶梯式切换)
VOS0 + PLL544MHz + D2CFGR(/2)     → ❌ 死锁 (已解决: 改用 D2PPRE2=/4)
VOS0 + PLL544MHz + D2CFGR(/4)     → ❌ 死锁 (已解决: 调整 FLASH_ACR)
```

## 7. DTCM 内存与 pyOCD 诊断

### 7.1 DTCM 布局

| 偏移 | 大小 | 内容 |
|------|------|------|
| 0x0000 | 256B | Timing vars (exec/period/heartbeat/直方图统计) |
| 0x00F0 | 4B | ACTIVE_ROUTES 计数 |
| 0x0100 | 256B | SENSOR_MAP[64] |
| 0x0200 | 128B | ACTUATOR_STATUS[32] |
| 0x0300 | 4KB | WIRE_MAP[1024] |
| 0x1300 | 1KB | LUT_DATA[256] |
| 0x1700 | 16KB | ROUTE_TABLE[1024] |
| 0x5700 | 8KB | PARAM_TABLE[512] |
| 0x7700 | 4KB | STATE_TABLE[256] |
| 0x8700 | 1KB | JITTER_BINS[256] |

### 7.2 Timing 变量 (0x20000000)

| 偏移 | 变量 | 类型 | 说明 |
|------|------|------|------|
| 0x00 | EXEC_MIN | u32 | ISR 最小执行时间 (cycles) |
| 0x04 | EXEC_MAX | u32 | ISR 最大执行时间 |
| 0x08 | PERIOD_MIN | u32 | ISR 最小周期 |
| 0x0C | PERIOD_MAX | u32 | ISR 最大周期 |
| 0x10 | SAMPLES | u32 | 样本总数 |
| 0x14 | LAST_ENTRY | u32 | 上次入口 DWT |
| 0x18 | HEARTBEAT | u32 | ISR 心跳计数 |
| 0x1C | CLOCK_HZ | u32 | SYSCLK 频率 |
| 0x20 | TIMER_HZ | u32 | TIM1 时钟频率 |
| 0x24 | EXEC_TOTAL | u32 | 执行时间累计 |
| 0x28 | PERIOD_EXACT | u32 | 精确 19200 命中次数 |
| 0x2C | PERIOD_NEAR | u32 | ±1 cycle 命中 |
| 0x30 | PERIOD_FAR | u32 | >10 cycles 偏离 |

### 7.3 抖动直方图 (0x20008700)

256 bin, 每个 uint32_t。bin[i] 记录周期偏离 (i-128) cycles 的次数。
中心 bin[128] = period 精确等于 19200。
