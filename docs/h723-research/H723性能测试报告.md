## 4. 对比分析

### 4.1 ESP32-S3 vs STM32H723

| 指标 | ESP32-S3 | STM32H723 (本项目) | 改善 |
|------|----------|-------------------|------|
| CPU 时钟 | 240MHz | **192MHz** | — |
| 内存技术 | DRAM (1T1C, 刷新) | **DTCM (6T SRAM, 免刷新)** | 根因 |
| 总线 | 双核共享 + WiFi DMA | **单核独占** | 零仲裁 |
| 抖动底噪 | 462ns p-p | **93.8ns p-p** | **4.9×** |
| 零抖动率 | 0% | **96.7%** | 质的飞跃 |
| WCET 可静态分析 | ❌ | ✅ | 架构确定性 |
| ISR 代码位置 | IRAM (DRAM 映射) | Flash + ART (可迁 ITCM) | |
| 额外硬件 | 74LVC574 外挂 | TIM1 内置影子寄存器 | |

### 4.2 抖动物理根因

```
ESP32-S3:
  DRAM 刷新 (每 7.8μs 一个 bank 刷新, 50-100ns)
  → ISR 执行期间撞刷新 → exec_max 跳变
  → 周期抖动 462ns p-p

STM32H723:
  6T SRAM 单元 (交叉耦合反相器锁存)
  → 免刷新, 零仲裁, 1 cycle 读写
  → 执行时间完全确定
  → 周期抖动 93.8ns (剩余来自 Flash 2WS + ART 未命中)
```

## 5. PLL 频率爬升测试

| 频率 | VOS | 分频器 | 结果 |
|------|-----|--------|------|
| 64MHz (HSI) | 默认 | /1 | ✅ 抖动≤15.6ns |
| 192MHz | VOS1 | /1 | ✅ 抖动 10.4ns |
| 192MHz | VOS0 | /1 | ✅ |
| 192MHz | VOS0 | D2CFGR+D1CFGR | ✅ |
| 272MHz | VOS1 | D2CFGR(/2) | ❌ 死锁 |
| 400MHz | VOS0 | D2CFGR(/2) | 未测试 |
| 544MHz | VOS0 | D2CFGR(/2或/4) | ❌ 死锁 |

> **结论**: 192MHz 及以下完全稳定。>272MHz 的频率切换需要进一步研究 Flash AC 时序。
