# DCL控制主机 — 通讯架构技术选型

> 基于五大主流PLC方案对比，确定三层通讯架构的选型路线

---

## 一、问题定义

### 当前状态

```
PC/Web IDE ──编译──→ 二进制任务帧 ─USART2(115200)─→ H723 MCU
                                                          │
                                                          └─→ 100us ISR执行
```

### 现状问题

| 问题 | 说明 |
|---|---|
| 第1层太弱 | USART2 115200bps，仅够下载程序，无法支撑在线监控 |
| 第2层空白 | 没有现场总线能力，无法接入工业IO/伺服/变频器 |
| 第3层空白 | 没有OPC UA/MQTT，无法上云/对接SCADA |
| 协议封闭 | 自研0xC0帧协议，无法与其他PLC/HMI互通 |

## 二、主流PLC的三层通信架构（调研结果）

### 2.1 第1层：工程通道（PC↔PLC）

| 厂商 | 协议 | 物理层 | 特点 |
|---|---|---|---|
| **西门子** | S7协议 | 以太网/USB | 下载程序+在线修改+诊断 |
| **罗克韦尔** | EtherNet/IP + CIP | 以太网 | 标签寻址，无缝IDE集成 |
| **欧姆龙** | Sysmac Protocol | 以太网/USB | 单软件配置所有设备 |
| **三菱** | MELSEC协议 | 以太网/USB/RS-232 | GX Works3一体化 |
| **施耐德** | EcoStruxure | 以太网/MQTT | 云端+边缘双通道 |

**共性**：全部基于**以太网**（TCP/IP或实时以太网），速率≥100Mbps，承载程序下载、在线监控、诊断。

### 2.2 第2层：现场总线（PLC↔IO/执行器）

| 厂商 | 协议 | 周期 | 最大轴数 | 同步精度 |
|---|---|---|---|---|
| **西门子** | PROFINET IRT | 250us-1ms | 128轴 | 1us |
| **罗克韦尔** | CIP Motion | 250us-2ms | 100+轴 | 1us |
| **欧姆龙** | EtherCAT | 125us-1ms | 192轴 | 100ns |
| **三菱** | CC-Link IE TSN | 31.25us | 256轴 | 1us |
| **施耐德** | SERCOS III | 62.5us-1ms | 64轴 | 1us |

**共性**：全部基于**工业以太网**（ EtherCAT / PROFINET IRT / CC-Link IE TSN / EtherNet/IP ），周期≤1ms，同步精度≤1us。

### 2.3 第3层：信息层（PLC↔SCADA/云）

| 厂商 | 实现 | 特点 |
|---|---|---|
| **西门子** | OPC UA Server + TSN | 内嵌，无需网关 |
| **罗克韦尔** | FT Gateway + OPC UA | FactoryTalk生态 |
| **欧姆龙** | SYSMAC Gateway + MQTT | 云+边缘协同 |
| **三菱** | SLMP + MES Interface | 直连MES数据库 |
| **施耐德** | EcoStruxure Cloud + MQTT | 直连Azure/AWS |

**共性**：**OPC UA Server**（工业4.0标准）+ **MQTT**（IoT协议），是所有旗舰的标配。

## 四、分层决策理由

### 第1层：以太网+TCP/IP（RPi↔H723）

| 决策项 | 选择 | 理由 |
|---|---|---|
| **物理层** | 以太网（RPi自带） | 无需额外硬件，100Mbps+，支持远程通信 |
| **传输协议** | TCP/IP | 可靠传输，与Web IDE天然集成 |
| **应用协议** | 自定义精简帧（保留0xC0帧） | 增量改动，兼容现有验证 |

> **关键洞察**：第1层不只是"下载程序"，后期要承载：在线监控(1KHz变量回传)、远程诊断、OTA升级。USART2 115200bps=11.5KB/s撑不住这些，以太网100Mbps=12.5MB/s够用。

**验证标准**：Web IDE能在1秒内读取所有1024路WIRE值。

---

### 第2层：EtherCAT主推，CANopen/Modbus补充

| 协议 | 定位 | 理由 |
|---|---|---|
| **EtherCAT** | 主推（必选） | 运动控制黄金标准，1us周期同步，与你的0抖动引擎完美匹配 |
| **CANopen** | 补充 | 入门级，低成本，连接传统传感器/变频器 |
| **Modbus RTU** | 补充 | 变频器/仪表行业标配，几乎必须支持 |

> **决策依据**：
> - EtherCAT是唯一能让你的<7ns抖动真正发挥价值的协议（PROFINET IRT抖动1us，看不到你的优势）
> - EtherCAT支持256轴（PROFINET 128轴，CC-Link IE 256轴），你的引擎理论上能跑128+轴
> - EtherCAT从站芯片便宜（ET1100 ≈ ¥20），成本可控

**验证标准**：通过EtherCAT控制4轴伺服做插补运动，同步误差<1us。

---

### 第3层：OPC UA + MQTT并列主力

| 协议 | 用途 | 理由 |
|---|---|---|
| **OPC UA Server** | SCADA/MES对接 | 工业4.0标准，语义模型，无需网关 |
| **MQTT** | 上云/IoT | 轻量，带宽友好，适合边缘到云 |

**验证标准**：OPC UA Client（如UAExpert）能读写所有变量；MQTT消息5ms内送达云端。

## 八、完整PLC通信方式图谱（含你的产品对标）

> 基于五大主流PLC调研，当前控制外部设备的全部通信方式如下

### 8.1 通信方式分类

| # | 通信方式 | 代表协议 | 典型应用 | 你的产品状态 |
|---|---|---|---|---|
| 1 | **接口直接IO** | GPIO、PWM、ADC/DAC、继电器 | 电磁阀、指示灯、传感器 | ✅ 已有GPIO+PWM |
| 2 | **脉冲/运动控制** | PUL/DIR、PWM、模拟量±10V | 步进电机、伺服、变频器 | ✅ 已有PUL/DIR+PWM |
| 3 | **工业以太网** | EtherCAT、PROFINET、EtherNet/IP、CC-Link IE TSN | 高速多轴同步、大数据 | ❌ 规划中 |
| 4 | **现场总线(串行)** | PROFIBUS DP、Modbus RTU、CANopen、DeviceNet、CC-Link | 变频器/仪表/传感器 | ❌ 规划中 |
| 5 | **IO-Link** | IO-Link (IEC 61131-9) | 智能传感器/执行器点对点 | ❌ 规划中 |
| 6 | **无线工业** | 5G URLLC、Wi-Fi 6、LoRa、WirelessHART | 移动设备/旋转物体/远距离 | ❌ 规划中 |

### 8.2 各方式详解

#### 方式1：接口直接IO

```
PLC → 光耦隔离 → 大功率驱动 → 接线端子 → 设备
```

| 信号类型 | 用途 | 适用设备 |
|---|---|---|
| 数字输出(DO) | 24V/0.5A | 电磁阀、指示灯、继电器 |
| 模拟输出(AO) | 4-20mA / 0-10V | 变频器、比例阀、调节阀 |
| 数字输入(DI) | 24V | 接近开关、按钮、限位开关 |
| 模拟输入(AI) | 4-20mA / 0-10V / PT100 | 温度/压力/流量传感器 |

#### 方式2：脉冲/运动控制

```
PLC → PUL/DIR → 步进/伺服驱动器 → 电机
```

| 信号类型 | 用途 | 适用设备 |
|---|---|---|
| PUL+DIR | 脉冲+方向控制 | 步进电机、伺服电机 |
| CW+CCW | 双脉冲控制 | 通用伺服 |
| PWM | 占空比控制 | 直流电机、加热器、比例阀 |
| 模拟量±10V | 速度/转矩指令 | 变频器、伺服驱动器 |

#### 方式3：工业以太网（高端控制核心）

```
PLC主站 ──确定性以太网──→ 分布式IO + 伺服 + 变频器
```

| 协议 | 周期 | 同步精度 | 适用场景 |
|---|---|---|---|
| EtherCAT | 125us-1ms | <100ns | 高速多轴、CNC、包装 |
| PROFINET IRT | 250us-1ms | <1us | 汽车制造、化工厂 |
| EtherNet/IP | 2-100ms | 通用CIP | 北美产线、罗克韦尔生态 |
| CC-Link IE TSN | 31.25us | <1us | 亚洲产线、三菱生态 |

> **结论**：EtherCAT + 你的<7ns抖动引擎 = 完美的性价比组合

#### 方式4：现场总线（工业领域的"普通话"）

```
PLC主站 ──串行总线──→ 远程IO + 变频器 + 仪表
```

| 协议 | 速率 | 拓扑 | 适用场景 |
|---|---|---|---|
| Modbus RTU | 115.2kbps | 总线型 | 最通用（变频器/仪表/传感器） |
| PROFIBUS DP | 12Mbps | 总线型 | 西门子生态专用 |
| CANopen | 1Mbps | 总线型 | 移动设备、医疗、机器人 |
| DeviceNet | 500kbps | 总线型 | 北美工业 |
| CC-Link | 10Mbps | 总线型 | 三菱生态 |

> **结论**：Modbus RTU是工业传感器的事实标准，必须支持

#### 方式5：IO-Link（智能传感器"USB"）

```
PLC主站 ──3线电缆(24V+Data)──→ 智能传感器（供电+通信+参数配置）
```

**不可替代的优势**：
- 一根3线电缆同时供电(24V)和通信(双向数字)
- 远程参数配置：PLC可以修改传感器量程/阈值
- 故障诊断：传感器脏污/老化/断线可知
- 即插即用：不同品牌传感器统一接口

> **结论**：IEC 61131-9标准，西门子主推，2026年爆发式增长

#### 方式6：无线工业


```
移动设备/旋转物体/危险环境 ←─无线─→ 控制系统
```

| 技术 | 时延 | 可靠性 | 适用场景 |
|---|---|---|---|
| Wi-Fi 6 | 5-20ms | 中 | AGV、HMI、视觉 |
| 5G URLLC | 1ms | 99.999% | 远程控制、数字孪生 |
| LoRa | 秒级 | 高 | 远距离传感器 |
| WirelessHART | 1s | 高 | 过程工业 |
| IO-Link Wireless | 5ms | 高 | 旋转设备、滑环替代 |

> **结论**：5G是未来，但目前工业市场接受度有限
