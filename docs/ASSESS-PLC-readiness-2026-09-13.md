## 0. 一句话结论

- **作为「确定性运行时内核」：完成度很高，且有可复跑证据** —— 这一块超出同类个人项目的常见水平。
- **作为「一台能上现场的 PLC」：完成度约一半，成熟度不够。** 缺的**不是内核**，
  而是四块外围：**IEC 语言前端 / 组态工具 / 通信面 / 工业级验证与认证**。
- **作为「求职作品」：内核够硬，门面不够** —— README 已与代码脱节，无演示、无录屏。

## 3. 三个「本质」缺口（比功能清单更要紧）

### ① 无看门狗 ⇒ **没有自恢复能力** ★ 最致命
取证：`grep -rn "IWDG\|WWDG" src/` ⇒ 只命中 `main.c` 里**读复位原因用的位名注释**
（`WWDG1RSTF`/`IWDG1RSTF`），**零实现**。
⇒ 我们所有"确定性"成果都建立在**"程序一直正常"这个未验证的假设**上。
PLC 的可靠性底线是"跑飞 / 受干扰 ⇒ **自动恢复** ⇒ 进安全态"——**这条路径目前不存在**。

### ② 成熟度最薄弱处：**异常路径与长稳几乎零覆盖**
**今天这一件事就是实证**：一个 **115200 连续帧下几乎必然触发**的缺陷
（ORE 溢出标志未清 ⇒ 接收自锁死），**存活了整条开发周期**，
靠 4 轮外部审计 + 一整天排查才定位。它表现为"偶发"，本质是"必然"。
取证：`故障注入 / 长稳 / 老化 / soak` 在 docs 里**零命中**（只有 GAP 文档说"应该做"）。
⇒ 缺两类测试：**错误注入（0）** 与 **长稳 72h（0）**。
**这才是"成熟度"的真正门槛：能不能在异常路径下仍然确定。**

### ③ 只有一条通信通道
取证：`ETH_BASE / CAN1_BASE / FDCAN / 0x40028000` 在 `src/` 里**零命中**。
⇒ 工业场景的"双通道冗余"做不到；H723 硬件其实带以太网 MAC+DMA，代码为 0。

## 6. 如果只做三件事（按性价比）

1. **看门狗 + 失效安全闭环**（半天~1 天）
   补上"可靠性身份"，且**天然可录屏**：故障注入 ⇒ 200ms 内复位 ⇒ 进安全态 + 复位原因可读。
   一句话叙事："异常注入下 200ms 内自恢复并进安全态"。★ 与 GAP 文档的排序一致。

2. **错误注入 + 长稳回归**（1~2 天）
   把今天的教训固化成套件：通信侧覆盖"非法帧 / 半帧 / 波特率错 / 持续灌满 / 长时间跑"；
   I/O 侧覆盖"断线 / 超量程 / 越界"。**这是从"能跑"到"成熟"的唯一路径。**

3. **README + 演示 + 录屏**（1 天）
   求职必需。当前 README（455 行）内容不差，但**停在 09-11**，与今天的 485 结案、
   性能优化、编码闸门全部脱节 —— 外人读到的是一份过时快照。

建议对外的口径是：

> **"STM32H7 单核 100µs 确定性 PLC 内核：Modbus RTU + 下载前静态校验 + ≤1 拍热更新
> + SD 黑匣子；全部结论可复跑、有 A/B 对照。"**

### 8.2 净效果：一减两增，但**净值是前进**

- **功能清单 −1**（掉电保持没了）。但按本项目第一条铁律"**宣称必须等于实现**"：
  之前的状态是**谎报有**（ACK + `dirty` 清零 + 每次"保存"重启机器），现在**明确没有**。
  ⇒ **这是前进，不是退步**：一个不存在的功能被诚实地标注，比一个声称存在却会重启机器的功能安全得多。
- **"确定性内核"这一档 +1**：闸门把"ISR 热路径纯度"从**靠人记得**变成**构建不过**——
  它守的正是"100µs 硬拍是确定性的"这句宣称（ISR 混入 flash ⇒ WCET 不可预算）。
- **"可审计性"这一档 +1**：4 个新可读面 + 1 个构建期闸门 + 一份含**排除表**的缺陷报告。
  ★ 但同一天里那个闸门**自己出了 4 个"会误报合规"的 bug** ⇒ 它进流水线前
  **必须先用"故意把函数移出 ITCM"证明它能失败**（已列为待做）。

### 8.3 对 §5 三种用途判定的影响

- **求职作品**：**↑ 明显变好**。多了一个能讲的故事：*一条隐藏了一天的"I​SR 调用树必须全在 ITCM"
  不变量被破坏 ⇒ 定位（5 条假设逐个排除）⇒ 变成构建期闸门*；而且**宣称与实现重新对齐**。
- **确定性运行时内核**：**↑ 更硬**（闸门 + 观测面）。
- **能上现场的 PLC**：**→ 基本不变**（缺的仍是语言前端/组态工具/通信面/工业验证四块），
  且掉电保持的缺失让这一档**略远**——老实说。
