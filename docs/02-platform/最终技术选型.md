## 一、核心决策：双网口直连架构

```
                    ┌─────────────────────────┐
                    │    PC/IDE (工程站)       │
                    │   DCL CLI / Web IDE     │
                    │   编译 + 监控 + 调参    │
                    └────────────┬────────────┘
                                 │ 以太网TCP:502/UDP:503
                    ┌────────────┴────────────┐
                    │   STM32H723 (确定小脑)    │
                    │   100us ISR │ <7ns抖动   │
                    │   火车模型时间表         │
                    │   [0-5us]路由扫描        │
                    │   [5-15us]★通讯窗口      │
                    │   [15-97us]余量B         │
                    │   [97-100us]DMA输出      │
                    └──────┬──────┬───────────┘
                           │      │
                    ┌──────┘      └──────┐
                    │                     │
               ┌────┴────┐         ┌─────┴─────┐
               │ 工程通道  │         │ 现场总线   │
               │ DP83848  │         │ LAN9252   │
               │ RJ45 #2  │         │ RJ45 #1   │
```

## 二、分层选型（终版）

### 2.1 第1层：PC↔H723 工程通道（以太网直连）

| 选项 | 结果 | 理由 |
|---|---|---|
| ~~USART2~~ | ❌ 弃用 | 115200bps太慢，2026 Q4起迁移到以太网 |
| ~~RPi CM4中间层~~ | ❌ 简化 | 电脑直连H723，去掉中间人，减少延迟 |
| **以太网TCP/IP → DP83848** | ✅ **选定** | H723内置MAC，DP83848 ¥8模块，100Mbps=12.5MB/s |
| 传输协议 | 自定义0xC0帧 over TCP:502 + UDP:503 | 帧同步MAGIC扩展为4字节，支持流媒体监控 |

**帧协议（终版）：**
```
[0xC0][CMD:1B][LEN:2B][PAYLOAD][CRC16:2B]

命令码：
  0x10 DEPLOY  — 下发行路表二进制
  0x11 START   — 启动ISR引擎
  0x12 STOP    — 停止ISR引擎
  0x13 RESET   — 复位引擎
  0x20 READ    — 读取WIRE值
  0x21 WRITE   — 强制写WIRE
  0x30 TELEMETRY — 心跳+状态推送（新增）
```

### 2.2 第2层：现场总线（多选并存）

| 协议 | 定位 | 优先级 | 硬件方案 | 软件方案 | 开发量 |
|---|---|---|---|---|---|
| **Modbus RTU** | 通用变频器/仪表 | **P1必备** | MAX485 (¥3) | FreeModbus | 5人天 |
| **IO-Link** | 智能传感器 | **P1推荐** | TEE110 PHY | 自研协议栈 | 10人天 |
| **CANopen** | 移动/小型设备 | **P2** | TJA1050 (¥3) | CANopenNode | 10人天 |
| **EtherCAT** | 高速多轴运动 | **P3** | ET1100 (¥20) | SOEM主栈 | 30人天 |
| **EtherNet/IP** | 北美市场 | 暂缓 | — | — | — |
| **PROFINET** | 西门子生态 | 暂缓 | 专用ASIC | — | — |

> **决策理由**：Modbus是工业事实标准必须做；IO-Link是传感器领域爆发点；EtherCAT是你的抖动引擎最佳拍档；CANopen是入门级的性价比选择。

## 三、硬件接口定义

### 3.1 确定小脑（H723）物理引脚

| 功能 | 引脚 | 方向 | 备注 |
|---|---|---|---|
| **以太网RMII** | PA1,PA2,PA7,PB0,PB1,PB5,PB11,PB12,PB13 | 外接DP83848 PHY | PC直连，Phase 1 |
| **EtherCAT** | SPI3 (NSS/SCK/MISO/MOSI) | LAN9252 ASIC | Phase 2 高速同步 |
| **CAN-FD** | PD0 (CANH), PD1 (CANL) | TJA1050 | CANopen |
| **RS-485** | PD5 (TX), PD6 (RX) | MAX485 | Modbus RTU |
| **IO-Link** | PE6 (TX), PE7 (RX) | TEE110 PHY | 智能传感器 |
| **步进脉冲** | PE11 (PUL+), PE13 (PUL-) | 差分驱动 | 42步进电机 |
| **方向信号** | PE12 (DIR+), PE14 (DIR-) | 差分驱动 | |
| **模拟输入** | PA0-PA7 (8ch) | ADC1 12bit | 传感器 |
| **模拟输出** | PA4,PA5 (2ch) | DAC1 | 变频器 |
| **数字输入** | PC0-PC7 (8ch) | 光耦隔离 | 接近开关 |
| **数字输出** | PE0-PE7 (8ch) | 继电器驱动 | 电磁阀 |

### 3.2 未来信息层（Phase 3+, 可选 RPi/Linux 主机）

> **当前 Phase 1**：PC直接连接 H723，不经过RPi中间层。

|---|---|---|
