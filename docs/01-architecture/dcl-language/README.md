# DCL 语言规范（合并版）

> 将三份历史文档合并为统一权威规范，消除矛盾，按主题拆分便于阅读。

## 合并说明

本目录合并了以下三份历史文档：

| 源文档 | 行数 | 特点 |
|--------|------|------|
| `DCL语言规范-v1.0.md` | 629 行 | 语言结构 + 完整原语 + 二进制格式 + 操作码表 |
| `DCL语言系统性说明.md` | 304 行 | 设计哲学 + 硬件映射 + 与其他语言对比 |
| `DCL语言编程规范.md` | 869 行 | 逐原语详细语法 + 参数表 + 验证状态 |

**合并原则：**
1. 内容去重，保留最完整准确的描述
2. 矛盾点以编译器（`ide/compiler/dcl_compiler.py`）实际实现为准
3. 版本以 v2.0（已验证状态）为基准
4. 按主题拆分为多文件，单文件不超过 500 行

### 主要矛盾点与最终采纳

| 矛盾点 | 三份文档各自说法 | 最终采纳 | 依据 |
|--------|----------------|----------|------|
| 版本号 | v1.0 / v1.0 / v2.0 | **v2.0** | 编程规范 v2.0 基于完整验证测试 |
| DEADBAND 语法 | `, width` / 无 / `RANGE lo hi` | **FROM src [, param]** | 编译器 `_parse_unary` 实现 |
| OUTPUT 语法 | `FROM signal` 必选 / 无 / 无 FROM | **`TO target [FROM signal]`** | 编译器 FROM 可选，省略时 signal=name |
| MUX 参数顺序 | 无 / src1, src2, src3(错) / src1, condition, src2 | **`= val_true SELECT cond ELSE val_false`** | 编译器 regex |
| SCALE | 独立原语 / "已合并到SENSOR" / 无 | **两者并存** | 编译器支持 `SCALE name FROM src RANGE lo hi` |
| ALARM 操作符 | `> >= < <=` / 无 / `> <` | **`> >= < <=` 四种** | 编译器 cmp_mode 映射 |
| RATE/DEADBAND 验证 | 已验证 / 待验证 / 已验证 | **已验证** | v2.0 编程规范全面验证 |
