# 验证测试计划

> 每项测试标注 [Phase X] 表示在固件第 X 阶段执行。

## Phase 0：硬件验证 (2 周)

### 0.1 电源轨检查

| 测试 | 方法 | 通过标准 |
|------|------|---------|
| 3.3V 上电 | 示波器测量上电波形 | 无 >3.6V 过冲, 单调上升 |
| 1.2V 启动 | 示波器测量 | 1.14V-1.26V 稳定 |
| 5V 隔离 | 接 100Ω 负载测量 | 4.9V-5.1V |
| DC Bus 软启动 | 220V 上电, 测母线上电曲线 | 无 >350V 过冲, 上电时间 <1s |
| 纹波 | 示波器 AC 耦合 | <50mVpp @ 3.3V, <5Vpp @ DC Bus |

### 0.2 PWM 输出验证 (不接电机)

```python
测试步骤:
  1. 烧录测试固件 (PWM 开环: 固定 50% 占空比, 16kHz)
  2. 示波器探头接 U 相输出 (对 DC Bus 负端)
  3. 检查:
     - PWM 频率: 16kHz ± 1%
     - 死区时间: 500ns ± 50ns
     - 占空比: 50% ± 1%
     - 上下管直通: 在死区期间两个 PWM 都应为低
  4. 重复 V/W 相
```

### 0.3 电流检测验证

```python
测试步骤:
  1. 不接电机, 输出固定 50% 占空比
  2. 用钳形电流表夹 U 相线
  3. 读取 ADC1_JDR1 值和 INA240 实际输出电压:
     - 理论上: I=0 → INA240 OUT=1.65V (Vref/2)
     - ADC 读数应为 2048 ± 20 (12-bit)
  4. 偏置校准:
     - 记录 Iu/Iv/Iw 的零电流 ADC 值
     - 写入 PARAM 区作为校准偏移量
```

**评估：** [C] 这三项是伺服驱动器的标准通电测试，没有 V2.1 架构相关的特殊风险。

## Phase 1：DMA 连续搬运验证 (2 周)

### 1.1 ADC → DTCM DMA CIRC

```python
测试步骤:
  1. 配置 DMA1_S0: ADC1_JDR1 → DTCM_ADC_RAW, CIRC
  2. 开启 ADC 注入组, TIM1_TRGO 触发
  3. 在 main loop 中:
     - 每次迭代读 DTCM_ADC_RAW[0..3]
     - 写入一个循环缓冲区 (内存中, ~1KB)
     - 每 1000 次迭代翻转 GPIO PE2
  4. 1 秒后停止, 检查循环缓冲区:
     - 数据是否连续无跳变 (ADC 值应该缓慢变化)
     - 是否有重复帧 (DMA 重载时可能丢一个传输)
     - 是否每 31.25μs 一个新样本 (32kHz)
```

**通过标准：** ✅ 数据连续, 无重复/跳变, 样本间隔 31.25μs ± 1μs

### 1.2 SHADOW → TIM1_CCR DMA CIRC

```python
测试步骤:
  1. 配置 DMA2_S5: DTCM_SHADOW_CCR1 → TIM1_CCR1, CIRC
  2. 在 main loop 中:
     - 每 1000 次迭代改变 SHADOW_CCR1 的值 (比如 1000→2000→3000→1000 循环)
     - 示波器观察 U 相输出
  3. 检查:
     - 占空比是否变化 (1000/7500=13.3%, 2000/7500=26.6%, ...)
     - 变化时刻是否与 DMA 触发点对齐 (TIM2_CH4 触发)
     - 是否有占空比 "中间态" (CPU 写一半时 DMA 搬走了半更新值)
```

**通过标准：** ✅ 占空比变化平滑, 无中间态, 变化时刻与 DMA 触发对齐

### 1.3 SPI DMA 读编码器

```python
测试步骤 (配合 AS5048A 模块):
  1. AS5048A 固定在电机轴上, 手动缓慢旋转
  2. 配置 DMA1_S1: SPI1_RX → DTCM_ENCODER, CIRC
  3. 手动旋转编码器 360°
  4. 读取 DTCM_ENCODER 的值变化:
     - AS5048A 14-bit: 0-16383
     - 值应从 0 上升到 16383 再回到 0
     - 应无跳变 / 断码
  5. 加速旋转:
     - 检查是否有读数丢失 (高速时 DMA 可能跟不上)
```

**通过标准：** ✅ 编码器读数连续, 全程 0-16383 无跳变, 高速无丢失

## Phase 2：电流环验证 (2 周)

### 2.1 开环电流阶跃响应

```python
测试步骤 (电机锁定):
  1. 锁定电机轴 (用手或台钳夹住)
  2. 配置 Iq_ref = 0, Id_ref = 0.5A (阶跃)
  3. 示波器测量:
     - CH1: INA240 输出 (相电流)
     - CH2: SHADOW_CCR1 (占空比指令)
  4. 测量:
     - 从指令发出到电流达到 90% 的时间 (tr)
     - 超调量 (Mp)
     - 稳态误差 (ess)
```

**通过标准：** tr < 500μs, Mp < 10%, ess < 2% (1-2kHz 带宽)

### 2.2 闭环电流跟踪

```python
测试步骤 (电机空载):
  1. 电机自由旋转, Iq_ref = 正弦波 100Hz/1A
  2. 示波器测量:
     - CH1: Iq_ref (由 GPIO DAC 输出)
     - CH2: 实测 Iq (从 SHADOW 反算)
  3. 检查:
     - 相位延迟
     - 幅值衰减
  4. 增加 Iq_ref 频率直至幅值衰减到 -3dB
     → 该频率 = 电流环带宽
```

**通过标准：** 基础版: 带宽 >1kHz, 相位延迟 <45° @1kHz

## Phase 3：系统集成测试 (2 周)

### 3.1 启动/停止序列

```python
测试 10 次冷启动:
  每次上电 → 使能 → 电机启动 → 运行 10 秒 → 停止 → 断电
  记录:
  - 启动是否每次都成功 (ALIGN → OPENLOOP → CLOSED)
  - 从使能到闭环的时间
  - 是否有异常震动/噪音/过流
```

**通过标准：** ✅ 10 次中 9 次成功, 启动时间 <2s

### 3.2 速度阶跃响应

```python
电机空载:
  指令: 0RPM → 1000RPM 阶跃
  测量: 上升时间, 超调, 稳态误差

加载 50% 额定转矩:
  指令: 固定 500RPM
  突加负载: 0% → 50% 阶跃
  测量: 速度跌落, 恢复时间
```

**通过标准：** 上升时间 <50ms, 超调 <10%, 负载扰动恢复 <20ms
