# 功率级设计

> 本文档设计伺服驱动器的功率级，涵盖：整流、IPM、电流检测、保护。
> 目标平台：SVD-2100 (基础版, ¥499)

---

## 1. 系统电压架构

```
220VAC 输入
  │
  ├─→ 保险丝 (5A, 慢断)
  ├─→ NTC 热敏电阻 (5D-15, 限制浪涌)
  ├─→ EMI 滤波器 (共模扼流圈 + X电容)
  ├─→ 整流桥 (GBU806, 800V/6A)
  ├─→ 滤波电容 (2×470μF/450V, 总 940μF)
  └─→ DC Bus: ≈310V (空载) / ≈220V (满载)
       │
       ├─→ 泄放电阻 (100Ω/20W + IGBT 控制)
       └─→ FSB50550AB IPM → U/V/W 输出

24V 控制电源输入
  │
  ├─→ DC-DC: B0505S-2WR2 → 隔离 5V (编码器供电)
  └─→ LDO: AMS1117-3.3 → 3.3V (MCU 和逻辑)
       └─→ LDO: AMS1117-1.2 → 1.2V (MCU 内核)
```

### 1.1 电源树评估

| 输出 | 电压 | 电流 | 负载 | 来源 |
|------|------|------|------|------|
| DC Bus | 310V | 3A max | IPM | 220V整流 |
| 控制 3.3V | 3.3V | 500mA | MCU+逻辑 | 24V→DC-DC→LDO |
| 内核 1.2V | 1.2V | 300mA | MCU 内核 | 3.3V→LDO |
| 编码器 5V | 5V (隔离) | 200mA | 编码器 | 24V→隔离 DC-DC |

**评估：** [C] 24V→5V 隔离 DC-DC (B0505S-2WR2) 提供 2W=400mA，编码器只需要 200mA，余量充足。1.2V LDO 从 3.3V 跌到 1.2V，压降 2.1V×300mA=630mW，AMS1117 不需要散热片（SOT-223 封装最大 1W）。

## 2. IPM 电路

### 2.1 FSB50550AB 引脚连接

```
FSB50550AB (SOP-29 封装)
  ┌──────────────────────────┐
  │ VDC (P)      COM (N)    │← DC Bus 310V / GND
  │ U, V, W                 │→ 电机
  │                          │
  │ VCC (H)      VCC (L)    │← 15V (来自板载 15V DC-DC)
  │                          │
  │ HINU, HINV, HINW        │← HCPL0630-1 (U相上管 PWM)  [C]
  │ LINU, LINV, LINW        │← HCPL0630-2 (U相下管 PWM)  [C]
  │                          │
  │ CIN                      │← 过流报警输出 (开漏)  [C]
  │                          │  → 经光耦隔离 → MCU GPIO
  │ FO                       │← 故障输出 (开漏)
  │                          │  → 经光耦隔离 → MCU TIM1_BKIN
  │ NTC                      │← 内部热敏电阻
  │                          │  → MCU ADC1_IN15
  └──────────────────────────┘

PWM 信号路径:
  TIM1_CH1  ─→ HCPL0630 ─→ FSB50550AB HINU  (U 相上管)
  TIM1_CH1N ─→ HCPL0630 ─→ FSB50550AB LINU  (U 相下管)
  TIM1_CH2  ─→ HCPL0630 ─→ FSB50550AB HINV  (V 相上管)
  TIM1_CH2N ─→ HCPL0630 ─→ FSB50550AB LINV  (V 相下管)
  TIM1_CH3  ─→ HCPL0630 ─→ FSB50550AB HINW  (W 相上管)
  TIM1_CH3N ─→ HCPL0630 ─→ FSB50550AB LINW  (W 相下管)
  TIM1_BKIN ←─ 光耦 ←─ FSB50550AB FO (硬件过流过温直接刹车)
```

### 2.2 PWM 死区配置

```c
// TIM1 中心对齐模式, 16kHz PWM
TIM1_CR1 = TIM_CR1_CMS_1;         // 中心对齐模式 2
TIM1_PSC = 0;                      // 不分频 (240MHz)
TIM1_ARR = 7500;                   // 240MHz/7500 = 32kHz → 16kHz PWM (中心对齐 x2)

// 死区时间 (来自 RM0468 §27.4.11)
// DT = (PREDIV × DTG + 1) × 1/tCK
// 目标: 500ns 死区 (IGBT 安全开关)
TIM1_BDTR = (3 << 24)              // DTG[7:0] = 120 → (120+1) × 4.17ns = 504ns
          | (1 << 16)              // 锁死 DTG, 运行时不改
          | TIM_BDTR_MOE           // 主输出使能
          | TIM_BDTR_AOE           // 自动输出使能
          | TIM_BDTR_BKP;          // BKIN 极性 (高电平有效)
```

**评估：** [C] 500ns 死区对 FSB50550AB 的 IGBT 是安全的（datasheet 要求 ≥200ns）。中心对齐模式 PWM 的电流采样窗口在载波谷底和峰顶，各有一段采样窗口。

## 3. 电流检测

### 3.1 INA240 连接

```
                    INA240A3QDRQ1 (SOIC-8)
                    
  ┌─────────────────────────────────────┐
  │                                     │
  │  IN+ ─┬─ 分流电阻 (5mΩ, 3W)         │
  │        │   │                        │
  │  IN- ─┘   └─ DC Bus 负端             │
  │                                     │
  │  REF1=GND, REF2=GND  → 增益 50V/V  │
  │                         满量程:     │
  │                         5mΩ × 10A × 50 = 2.5V  │
  │                          → ADC 0-3.3V 范围内   │
  │                         电流分辨率:             │
  │                         3.3V/4096/50/5mΩ = 3.2mA/LSB │
  │                                     │
  │  OUT ─── 100Ω ─── 10nF ─── ADC1_IN1 │
  │                                    │
  │  (CMP 滤波: 截止频率 ≈ 160kHz)      │
  └─────────────────────────────────────┘

三相各一片:
  × 相: INA240 #1 → ADC1_IN1 (U 相)
  × 相: INA240 #2 → ADC1_IN2 (V 相)  
  × 相: INA240 #3 → ADC1_IN3 (W 相)
```

### 3.2 ADC 采样时序

```
PWM 中心对齐模式 (16kHz):
                    ┌───────┐          ┌───────┐
  上管 ON: ─────────┤       ├──────────┤       ├────
  下管 ON:          └───────┘          └───────┘
               ▓ 采样窗 ▓            ▓ 采样窗 ▓
               ↑ TIM1_TRGO           ↑ TIM1_TRGO
               (OC4REF)              (OC4REF)
               触发 ADC 注入组        触发 ADC 注入组

每次 PWM 载波有 2 个采样点 (谷底和峰顶),
每个采样点触发 ADC 注入组同时采样 Iu/Iv/Iw。

ADC 转换时间 (RM0468 §28.4.13):
  SMP=32 cyc → 32×8.33ns = 266ns 采样 + 12.5 cyc 转换
  总时间 = (32+12.5) × 8.33ns ≈ 371ns/通道
  3 通道注入组总时间 ≈ 3 × 371ns = 1.11μs

PWM 16kHz = 62.5μs 周期:
  谷底和峰顶各一个采样点 → 每 31.25μs 一次电流采样
  → 电流采样率 32kHz — 理论上可以支持 16kHz 电流环带宽
```

**评估：** ⚠️ [R] INA240 输出端 RC 滤波（100Ω+10nF）的截止频率 160kHz。INA240 自身带宽 400kHz。ADC 采样率 32kHz。这条链路的带宽瓶颈在 ADC 采样率（32kHz），而不是 INA240。对基础版 1-2kHz 电流环绰绰有余，但对旗舰版 30kHz 不够——旗舰版需要额外的过采样技术或者用差分直接采。

## 4. 过流硬件保护 (不可绕过)

```
电流路径:
  INA240 OUT ──→ COMP1_INP (H723 内置比较器)
                   COMP1_INN ← DAC 输出 (阈值)
                   COMP1_OUT → TIM1_BKIN (硬件刹车)

时序:
  过流发生 → COMP 输出翻转 → TIM1_BKIN 刹车
  ↑ 全部硬件路径, 不经过 CPU, 不经过 DMA
  总延迟: <100ns (COMP 比较延迟 + TIM1 BKIN 响应)

参数:
  过流阈值: 10A (5mΩ × 10A × 50 = 2.5V)
  DAC 输出: 2.5V (用 H723 的 DAC1 输出)
  滞后: ~50mV (防止在阈值附近抖动)
```

**评估：** [C] 这条路径没有软件参与。COMP 输出直接连 TIM1_BKIN（硬件内部连线），从过流发生到 PWM 刹车 <100ns。这是 STM32H7 的标准安全特性，不是新设计。

## 5. PCB 布局约束

1. **功率地和控制地必须在 IPM 下方单点连接**，严禁大面积共地
2. **INA240 输入线 (分流电阻两端) 必须差分走线**，等长、紧耦合
3. **HCPL0630 PWM 隔离光耦两侧保持 2mm 爬电距离**
4. **TIM1_BKIN 走线必须远离功率回路**——它是安全线，干扰会导致误刹车
5. **编码器 DB9 连接器的 SHIELD 接机壳地**，不接控制地
6. **MCU 退耦电容：每对电源脚一个 100nF，整体 4.7μF**
