## ★ 2026-09-17 00:26 续 —— 用户问"成熟工业 PLC/运动控制卡怎么做" ⇒ 查实物手册定案

**查到的工业做法（不是类比，是手册/标准原文）**：

| 层 | 做法 |
|---|---|
| ① 配置层 | **硬件跳线/DIP**：雷赛 DMC2210 有"板卡跳线设置"专章；ADLINK AMP-304C 限位 NO/NC 用**板上 DIP 硬件设置、无需软件初始化**；CMP 电平（5V/24V/OC）用跳线。<br>**工具 + 配置文件存卡**：ADLINK PCI-8132 的 `Motion Creator` → `Axis Configuration`（脉冲模式/编码器源/**限位逻辑**/回零模式/中断因子）→ **`8132.cfg`**，掉电保持上电装载。= ESI / CiA 301 `0x1018` / PROFIdrive 一族。 |
| ② 运行时状态机 | **CiA 402 / PLCopen `MC_Power`**：请求**抽象状态**（Controlword），**等 Statusword 到 `OperationEnabled`**，超时 ⇒ Fault。★ 不是"发个 bit 就算使能"。 |
| ③ 物理链路 | 运动卡每轴标准信号 = **`SVON` 输出 + `RDY`/`SRDY` 输入**（ADLINK 8132/AMP-304C、静安 MPC3024AC）。Radonix 明写：Ready 异常 ⇒ **报卡并停止该轴**。`SON` 是 open-collector NPN ⇒ **极性是接线约定，要求驱动器匹配**。 |

**两条制度性的（比选型更重要）**：
- ★★★ **fail-closed**：**没有配置 ⇒ 不允许使能并报错**。⇒ **这正是我们最缺的**：我们现在"未配置 ⇒ 猜一个 0" = 三者里最坏（**看起来接受了，其实跑错**）。
- ★★ **安全不由软件默认值定义**（EMG/STO/安全继电器硬线兜底）；且**安全态按轴不同**（垂直轴去使能 = 掉力滑车）⇒ 工业做法是"保持使能 + 无脉冲"配抱闸。

**映射结论**：
- **① 改默认值 = 反工业实践**（工业界没有"编译期极性"概念）。现有 `0` 之所以错，正因它**是"对硬件的假设"** ⇒ 正确修法是**取消假设**，不是换一个假设。
- **② 持久化装置配置 = 正确落法**，而且**我们有现成骨架**：`0x4A DEVICE_DESC` 自述"我们的 ESI 等价物"、已用 `product_code+revision`（点名 CiA 301）、**已有 append-only 尾块模式**、**设备表已记录 TB6600 接线 revision** ⇒ 加参数 = 沿用已有机制。
- ★★ **位置必须选对**：极性是**机器属性**，**不能跟程序包走**（GAP-11 那套是程序包级）—— **换程序不该改变驱动器极性** ⇒ 独立"装置配置"区（magic+rev+CRC+上电装载）。
- **③ 不是"选项之一"，是独立的第二件事**：指令 vs 反馈分离 + 超时判故障。★ 我们**已具备**（`op=19` 同时报 `ena`/`PE9`），缺的只是**判据用它**。

**落地形状（建议 v2.2.0 核心项，需 A/B + 回归）**：装置配置区（独立于程序包）/ `0x4A` 追加尾块声明偏移+版本+**实测极性** / **去掉编译期默认值⇒出厂=未配置** / **fail-closed**（未配置⇒拒绝使能 + `PE9` 保持物理失能，**方向要按 `pol` 反算，不能再写死**）/ 状态机化（指令≠实读 ⇒ 计数+标志）/ `step_stop_safe()` 的"安全"按轴显式化。

**判据（都要能失败）**：① 未配置 ⇒ 必须拒绝使能；② 换程序包不得改变极性；③ `0x4A` 追加块不改前 N 字节；④ "指令≠实读"可注入复现。

**落档**：`docs/RELEASE-v2.1.0.md` **§6.2**（新增，含全部出处）。契据闸门复跑 ✓（F 类 421 行 / D 类 48/48）。

### 四、✅ 交付：`examples/h723_step_bounded_position.dcl`（**已跑通**）

结构（全部用 DCL 原语，**没有 ABS/MOD 就凑出来**）：
```
SENSOR ang FROM sensor[1]                    # 角度 0..360
ADD a2 FROM ang BY=-360 ; GE wrap ang≥180 ; SEL fbk → [-180,180)   # ★ 最短弧折角
SUB err FROM tgt(-40.0 = 320°) BY=fbk        # 带符号、最短弧
MUL eneg err×-1 ; MAX eab = |err|            # ★ 用 MAX 凑绝对值
MUL raw = kp×|err| ; LIMIT hz0 [60,3000]     # ★ 先对**正幅值**钳位
GE drv |err|>0.5 ; MUL hz = hz0×drv          # 误差带自停
GE dpos err≥0 ; LOGIC dneg = NOT dpos        # ★ 方向由误差符号定（双极性）
OUTPUT hz/dneg/one/lim → wire[12..15]        # 运动请求（程序面）
```
**实测结果**：
- 起点 294° → 目标 320°，`fbk` 在 ±180 处正确折回（**不再跑飞**），`hz` 全程 **[300,703] 未饱和** ⇒ **有界**
- **到位：角度 319.92°、误差 0.08°、`hz=0` 自停**
- **保持：12 点 × 0.5 s ⇒ 峰峰 0.000°、max|Δ| 0.000°（零漂移，比 1 LSB 还稳）**
