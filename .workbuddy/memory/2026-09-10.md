## ★ 本板实测频率天花板 ≈465MHz (docs/REF-frequency-ceiling.md)
- 450/460 可跑; 470 起不运行; 480/500/520/550 全不运行
- 已排除: 晶振频率 / PLL 分频 / FLASH 等待态 / 总线带宽 / VOS 写入 /
  PLL 输入频率 / CPUFREQ_BOOST
- 剩余最可疑: VCORE 未达 VOS0 水平 或 板级供电/VCAP (需万用表量;
  本机 LA 是 Logic 8, 无模拟输入)
- 用户决策: 测试期固定 **400MHz**; 芯片电路设计留到 PCB 阶段

## ★ 方法论 (写进 README 与 skill)
- **频率/时序类结论必须用 LA 外部证据** —— SWD 在 CPU 跑不住时会失步,
  会给出完全错误的结论 (曾据此误判"300~340MHz 断崖", LA 实测 450MHz 正常)
- 用 SWD 读"运行态"寄存器前**不要先 reset** —— `pyocd reset halt` 会把 RCC 打回复位默认值
- 测频工具判据: 跳变数 < 200 一律判"没在跑"(否则少量跳变也会算出"正确频率")

## 硬件接线 (docs/HARDWARE-PINOUT.md)
- LA: CH4 ← PA8 (拍输出) / GND ← GND (必接) / CH1 ← PA9 (阶段1 协议, 待接)
- 本机克隆 Logic 8 **双通道不可靠** → 只用单通道
- 调试口 H1 (2×4P): 1=SWCLK_PA14 2=SWDIO_PA13 3=RST 4=+5V 5=USART1_RX_PA10 6=USART1_TX_PA9 8=3.3V
- 板载 LED 在 PG7; PA8 引在 2×30 扩展排针
