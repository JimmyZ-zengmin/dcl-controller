## 〇、最贵的十八条（先读这段；细节按编号查 `RULES-DETAIL.md`）

1. **用这个系统 = 写 DCL 程序，不是改固件**；要新能力**先判层**（§二）。
2. **不得把实时量挂主循环**（主循环 0.37 ms，拍 100 µs）。
3. **新增 SHM 域必须登记到唯一冷启动入口 `cold_start_reset()`**。
4. **判"物理状态"看引脚实读（`IDR`/`PE9`），不看逻辑位**；**`PE9=1` 才是使能**（5.15）。
5. **黑匣子槽头 = `[0]magic [1]tick [2]seq [3]ctrl`；环"变化才记" ⇒ 跨度必须由 tick 算**（§五/5.28）。
6. **"设了就算"必错**：凡配置量都要"**目标值 vs 读回值**"核对（5.15/5.32）。
7. **过闸门/构建绝不用管道**；**构建失败不许往下走**（**重试也要判退出码**，5.33/11.8）。
8. **判据必须能失败**，并配"**不该红的不红**"的反向判据（§四 判据禁忌）。
9. ★★ **"期望为 0/小"的判据必然是假绿 ⇒ 必须先配"正对照"**（5.23）。
10. ★★ **差分量的分子与分母必须同口径**（5.23）；**极值/分位数不免疫采样拍频，累积量才免疫**（5.27）。
11. **"值相同 ⇒ 不做"是危险判定**（11.4）。**"还欠着什么"必须配对计数，不能用 bool**（5.12）。
12. **门带引用计数、住资源定义处；先验参再拿门**（5.5/5.10）。
13. **测量期间不许做别的事**；**测前先装"前置条件闸门"**（§八）。
14. ★★ **`dclc` 自动分配必须跳过固件保留槽**（5.17）；**主机输入槽必须登记**（5.22）。
15. ★★ **"判据的速率"必须与被测量速率匹配；降档不是万能解，`LPF` 才是**（5.20）。
16. ★ **③层口径**：`OUTPUT` 不接受 `PERIOD=`（5.21）；`CONST` 不认科学计数法、`THR=` 只认字面量、`BY=`/`FROM` 只认已声明名（5.18）；**`LUT` 引擎有而 `dclc` 未暴露**（5.25）。
17. ★ **`SEQ` 步号是 1 起**（固件 `engine.c:474`）（5.24）。
18. ★★ **"能做"与"能验收"是两件事** —— 覆盖不到就判 SKIP，**不许变成 PASS**（5.26）。

## 二、架构使用规约（强制）

```
① 引擎核心 烧录 改它 = 换固件(必走 A/B + 12 套回归)  ② 外设能力 随核心版本化 + 能力位
③ DCL 程序 通信上传 + 持久化(SD)                     ④ 程序工程 上位机侧 .dcl + 清单 + 产物
```
**判层**：怎么算 ⇒ ③｜和外设怎么说话 ⇒ ②（**不是**新驱动）｜新的每拍行为/实时保证 ⇒ ①｜只是给上位机看的量 ⇒ SHM + `obs_anchor()`（**不是**加协议 op）
**实验八条**：观测走协议内通道（pyocd 最后手段）/ 控制走程序面（`0x10`+`0x11`）/ **要新能力先判层** / **每拍 → ISR/引擎，服务性 → 主循环** / 实验代码独立 patch / 运行期改动复位即恢复 / 判据能失败 / **新 SHM 域登记 `cold_start_reset()`**
★ **GAP-6 推论**：外设"多步操作"不能靠主循环跑阻塞事务 ⇒ 照 `adc_poll` 做**拍内每拍推进一步的状态机**。
★ **适用边界由测量决定**：AS5600 留主循环没问题（≈450 µs、`loop_gap_max_undecl=0`）。
**三条红线**：① 程序里不得有物理引脚号/总线地址（`dcl_static_check.py` 编译期拒）；② **不得破坏单写者**（已两次踩到：`TIM3`、**SD 卡**）；③ 不得把实时量挂主循环。

## 四、时基与仪器

- ★★★ **别拿调试单元当生产时基**：pyocd 断开时写 `DEMCR.TRCENA=0`（issue #1540）⇒ DWT 静默死，只有**断电重上电**能救。✅ 交付档时基 = **TIM5**（32 位/200 MHz ⇒ 5 ns）。
- ★ 单位随档变：拍 = **20000**（非 40000）、ISR 最长 ≈ **818**。`0x39 op=21` 看 `[0]档(1=TIM5) [2]自检Δ(=0 即死) [4]dwt_dead [6/7]pmin/pmax`；★ `g_per_cyc_*` 跨复位不丢 ⇒ **活性判据 = `0x13 RESET`→`0x11 START`→等 1 s→`pmin` 非 0**。
- 只读观测用 `connect_mode=halt`；★ **读固件全局量前绝不能 `-c reset`**；收尾必须 `-c go`。★ `pyocd reset` 不放收尾 —— 构建→flash→**让板子自己重启**→之后只走协议。★★ `pyocd halt` 把核留在停住状态 ⇒ 据此得过一串假结论（**协议能读的一律用协议**）。
- **判据禁忌**：① 空判据（恒 0/1）② **形状 > 幅度** ③ 先判掉量化伪影 ④ 同一性对照（A/B 先 sha + 同采样率）⑤ **反向判据** ⑥ 口径与被测量同量纲 ⑦ 覆盖不到判 **SKIP** ⑧ "等值"必须给噪声底容差（AS5600 1 LSB = 0.0879°）。
- 逻辑分析仪采样率反推 / USB 丢数据判别：见 `RULES-DETAIL.md` §二。

## 五、黑匣子（取证主力）

- 环 `0x24004000` 起，**960 槽 × 256 B = 240 KB**；槽 = `[4 字头][60 数据]`；头 = `[0]magic "DLBK" [1]tick [2]seq [3]ctrl`（**读反过 ⇒ 跨度错 3.96×，报出 4651 rpm**）。
- ★★★ **环"变化才记"** ⇒ 跨度随变化率变（实测 **380 ms**；轴不动时记录率 173~571/s、跨度 452~473 ms）⇒ **跨度必须 `(tick[last]-tick[first])/10000` 秒**（`blackbox.h:71` 的 "960 槽 = 96 ms" 是逐拍全量算法）。★★ **保留跨度 = 960 ÷ 变化率** ⇒ 运动时只剩 **~0.4 s** ⇒ **1.2 s 周期的形状验收做不了**。
- 取值：**pyocd API 单会话**（halt）读满 240 KB ≈ 1.4 s；★ **运动中途 halt** 才拿得到稳态段。
- ★ 量纲自检：`data[0]`=raw / `data[1]`=角度 ⇒ `|deg − raw×360/4096| ≤ 0.001°`。
- ★★ **槽位 `slot = seq % 960`，但 `seq` 会回绕** ⇒ 按 seq 切段切出**假不连续段**（只取到 128 条就是这么来的）；工具已加**一致性闸门**（矛盾退 **2**）。

## 六、程序持久化 + 内存地图

`.dcl` → 编译 → `0x45/46/47` 上传 → SD A/B 双副本 → 上电自动装载（不碰 flash）。`0x48` 96B：+52/56/60 = `txn_begin/commit/abort`；+64..76 = 开机装载结果；+80..92 = 卡上载荷头。
★★ **五道闸门**：帧 CRC16 / 清单 CRC32+total_len / 写后回读 memcmp / A/B+单调 seq / **装载时再跑同一套静态校验**（`prog_validate` 共用实现）。★ 发布前必做**"运行态 vs 持久态"对账**。
★★ **SD 日志"开机时开的"** ⇒ 卡插晚/换卡必须**显式重开**（5.29）；**判"在不在记"用 `s_log_blk` 前后差**。
