# 2026-09-13 — RS-485 PC→板子方向不通：收敛到"两个元件"

## 结论（这是今天最重要的产出）

板子↔PC 两条方向**分开测**，结论现在是对称且互斥的：

| 方向 | 路径元件 | 状态 | 证据 |
|---|---|---|---|
| 板子→PC | PD5 → 模块 TTL→485发送 → A/B总线 → dongle 485接收 → PC | ✅ 完好 | 最小固件从 PD5 反发 `DCL485TX-…`×200，COM15 逐字收到几千遍，TX timeouts=0 |
| PC→板子 | PC → dongle **485发送** → A/B总线 → 模块 **485→TTL接收** → 模块TXD → PD6 | ❌ 0 字节 | 见下 |

**对消之后只剩两个嫌疑元件**：① dongle 的 485 发送方向；② 模块的 485→TTL 接收方向。
A/B 极性 / 共地 / 板子侧固件与引脚 / "接错脚" **全部已排除**。

交接文档: `docs/485-COMM-QUESTION.md`（写给外部顾问，含建议的判别步骤）。

## 今天做到的四件硬事

1. **推翻了自己昨天的根因**：pyocd 每次会话开始与结束都复位目标，而诊断区在 DTCM
   ⇒ 早期所有"0 字节"读数都是**仪器伪影**。观测面改为**协议口 0x63**（全程不开调试器），
   并加了 AXI 启动计数器取证（读 6 次 = 启动 1..6 实锤）。
2. **整体视角一次取证**（`tools/mb_holistic.py`，同会话两批读数、中间并发发 237 帧）:
   `g_tick_count`/`g_mb_ticks`/HEARTBEAT Δ=8014/800ms（每拍都调，一次不落）、
   `enabled=1`、`src=0`（物理口）、寄存器读回全对；**DTCM RX 缓冲全 0**。
   ⇒ **软件无嫌疑**，"代码把通信挡住了"正式排除。
3. **写了一个干净固件**（`src/min_uart485.c`，`DCL_MIN_UART2` 档）:
   只用 HSI 64MHz 默认时钟树、零中断、零协议、零引擎；USART1 当纯文本观察窗（COM14，
   **不需要 pyocd**），USART2 挂 PD5/PD6 做真正接收。
   ★ 项目**本来就有** `src/min_uart.c` + `DCL_MIN_UART`（只测 USART1）—— 遇到"串口不通"
     先翻 CMakeLists/项目自带脚本，这条铁律第 6 条今天又应验一次。
4. **全端口逐脚活动扫描**（本固件最有价值的发明）:
   PC 灌 20262 帧期间，把 GPIOA..GPIOG **112 个脚**逐个设"输入+下拉"、各采样 40 万次，
   统计高电平比例与**跳变次数**。判据: 115200 真数据线 ≈ 57600 翻转/s，
   37ms 窗口期望 ≈2000 次；悬空脚拾音只有几十~几百 ⇒ 阈值 300 能分开信号与噪声。
   **结果: 有翻转的脚 = 0 个。** 静态高: PA10、PC8-11、PD2、PD5、PG15；PD6 恒 0。
   ⇒ 不是"插错脚"，是**信号根本没到 MCU 这一侧**。
   ★ 顺带解释了 PD5 静态高 = 模块 RXD 侧上拉 ⇒ PD5 那根线是接上的；PD6 悬空 = TXD 没接上。

## 今天顺手修掉的两个**自研**缺陷（都会污染判据）

1. ★★ **诊断钩子自己造出"到过字节"的假证据**（`mb_line_test` / `mb_line_probe`）:
   恢复引脚时先写 `MODER`(接回AF7) 再写 `PUPDR`(还停在下拉)，中间那一瞬 RX 被下拉成低
   = **一个 break 条件** ⇒ USART 必然收到 **1 个 0x00 + 1 次 FE**。
   症状: 每跑一次线检，`bytes`+1、`erracc` 多一个 FE —— **看起来正像"真有数据来了"**。
   发现路径: 干净固件里每轮扫描固定多出 1 字节 0x00 + 1 次 FE，一眼看出是自造的。
   修法: 恢复顺序 = AF 选择 → PUPDR 上拉 → **最后**才接 AF。
   ⇒ 通用教训: **诊断动作的"复原顺序"也会造出被测信号**；先置低（输入+下拉）后复原时，
     PUPDR 必须早于 MODER。
2. **扫 GPIOA 时不能边扫边打印** —— 观察窗 USART1_TX 就是 PA9，把它设成输入的那一刻起
   打出去的字全丢在空气里（第一版 16 行 PAxx 一行都没回来）。⇒ 采样结果先存本地、
   恢复之后再统一打印。
3. `build.sh` 的"生效开关"清单正则 `[A-Z_]*` **不含数字** ⇒ `DCL_MIN_UART2` 漏列。
   而这一段的目的正是"别被 CMake 缓存骗"，漏一个开关就是留一个静默洞。已修为 `[A-Z0-9_]*`。
